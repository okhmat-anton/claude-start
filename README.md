# claude-start — /start и общая база знаний агентов

- `project_start.md` — команда `/start`: интервью, генерация системы самосовершенствования проекта, подключение базы знаний.
- `knowledge/` — база знаний, общая для всех проектов. Формат единиц — `knowledge/FORMAT.md`; оглавление `INDEX.md` генерируется.
  - `lessons/` — уроки «триггер → действие» (одна ситуация = одна единица, ≤30 строк прозы, обязательные триггеры);
  - `stacks/` — справочники по стекам; `skills/` — переносимые скиллы (`scope: global` ставятся в `~/.claude/skills`);
  - `improvements/` — улучшения, принятые в одном проекте и предлагаемые в других: что сделать лучше в решении,
    модуле или коде; оценка владельца и оценка агента рядом, голоса по проектам — в `usage.json`;
  - `usage.json` — показы и применения уроков, голоса и оценки по улучшениям (обратная связь для уборки).
- `tools/knowledge.py` — lint / index / match / hit / new / improvements / vote / gc / stats. `tools/hook.py` — глобальные хуки Claude Code
  (уроки по триггерам, поправки владельца, уровень задачи, напоминание про retro).
- `tools/install.sh` — подключает хуки и глобальные скиллы к `~/.claude` (идемпотентно). `make install`.
- `evals/cases.json` + `tools/evals.py` — регрессия триггеров (офлайн) и поведения агента (`--live`, платно).

## Как знания попадают к агенту
1. `UserPromptSubmit` — хук подбирает до 3 уроков по ключам промта и вкладывает их в контекст.
2. `PreToolUse(Bash)` — до 2 уроков по шаблону команды (`docker compose up`, `ffmpeg … xfade`, `ssh … psql`).
3. `SessionStart` — размер CLAUDE.md, неразобранные поправки владельца, застрявшие кандидаты.
4. `Stop` — если правок ≥5, а retro не было, просит прогнать retro (один раз за сессию; не в простой и средней задаче).

## Уровень задачи — глубина протокола
Каждая новая задача с правками начинается с уровня: **простая** (сделать, проверить, закоммитить), **средняя**
(один круг урезанного ревью, упрощение только по диффу и улучшения по модулю, без уроков), **сложная** (до трёх
кругов взгляда Джобса, анализ кода на упрощение и улучшения, retro). Уровень — словом в промте («Сложная: …», `[средняя]`, «задача средней сложности»);
не назван — простая по умолчанию, агент перепроверяет (новый экран, несколько модулей, деньги или данные, неясные
требования) и при признаке предлагает выбор кнопками «Какой сложности задача?», сам не назначает. Процедура и таблица «шаг × уровень» —
`knowledge/skills/task-tier/SKILL.md` (глобальный скилл); хуки `UserPromptSubmit` и `PostToolUse(AskUserQuestion)`
пишут уровень в `~/.claude/task-tier/<session>.json`. Шаблон `/start` — раздел 4.19.

## База улучшений — там, где агент упрощает, он и улучшает
После блока правок субагент-упроститель (`/start` 4.11) предлагает не только упрощения кода, но и улучшения — решения
задачи, модуля, в котором шла работа, и кода, без лимита, по выгоде; улучшение — всегда вопрос владельцу, не правка.
Принятые уезжают в `knowledge/improvements/` (`knowledge.py new … --improvement`), каждый ответ владельца — голос
`knowledge.py vote <name> --project <проект> --answer accepted|rejected|deferred|na [--score 1-5] [--memory …]`; оценку владелец
ставит после того, как увидел результат. `knowledge.py improvements --project <проект> --stack …` подбирает под проект
ещё не решённые там улучшения по рейтингу; прогон всей базы по проекту — глобальный скилл `improve-sweep`, по слову
владельца. Формат единицы — `knowledge/FORMAT.md`.

## Как знания растут
retro в проекте → `knowledge.py new` (кандидат, `seen_in: [проект]`) → второй проект добавляет себя в `seen_in` →
`status: mature`. Применил подсказку → `knowledge.py hit <name>`. Раз в месяц `knowledge-gc` чистит по `usage.json`.

```
make lint    # формат единиц
make index   # пересобрать INDEX.md
make test    # lint + index --check + евалы триггеров
make gc      # отчёт уборки
```
