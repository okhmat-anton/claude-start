# FreeCAD без окна — модели скриптами (macOS, FreeCAD 1.1)

- Установка: `brew install --cask freecad` — около 3 минут и 1–2 ГБ, ставит `/Applications/FreeCAD.app`;
  проверено 11.2026 на FreeCAD 1.1.4 (Apple Silicon). Запуск из терминала Gatekeeper не блокирует.
- Без окна: `/Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd <скрипт.py>`. В PATH его нет — путь
  целиком; рядом лежат `freecad` (окно) и `python` (встроенный).
- Встроенный Python — 3.11, свой, не системный: `import FreeCAD, Part` работает только в нём, в venv проекта эти
  модули не импортируются. Линтеру скриптов моделей — `target-version = "py311"`, иначе пропустит синтаксис новее.
- Проверка установки за секунду: скрипт с `Part.makeBox(10, 10, 10)` печатает `box.Volume` (ждём 1000.0) и
  `FreeCAD.Version()`; код возврата 0.
- `print` скрипта идёт в stdout вперемешку с баннером версии — нужные строки фильтруй, статус бери по коду возврата.
- Агенту удобно так: параметры модели (размеры в мм, допуски) — константами наверху скрипта, `.FCStd` собирается
  из скрипта; правку человека в окне FreeCAD переносить обратно в параметры, а не править `.FCStd` руками.
- Под `freecadcmd` у скрипта `__name__` — имя файла, а не `"__main__"`: `if __name__ == "__main__"` молча не
  срабатывает — построение вызывай без проверки. Папки скрипта нет в `sys.path` — для соседнего модуля добавь её
  сам (`Path(__file__).resolve().parent`, `__file__` есть).
- Файл, сохранённый `freecadcmd`, не несёт `GuiDocument.xml`: в окне FreeCAD все детали скрыты — человек видит
  пустой вид. Показ — тот же скрипт через GUI (`.../bin/freecad скрипт.py`): `obj.ViewObject.Visibility = True`,
  цвет `ViewObject.ShapeColor`, сохранить из окна. Признак файла «для окна» — `GuiDocument.xml` в архиве (проверка
  тестом).
- Камеру, заданную скриптом при старте окна, FreeCAD перебивает своей (вид сверху), а `viewIsometric()` ещё и
  анимируется: ставь камеру по `QtCore.QTimer.singleShot(~1500, …)` через
  `setCameraOrientation(App.Rotation(0.424708, 0.17592, 0.339851, 0.820473), True)`, потом `fitAll()`, сохранение и
  снимок `ActiveView.saveImage(путь, 1600, 1000, "White")` — свой кадр до показа человеку.
- Скрипт в окне закрывает себя сам, в `finally` таймера: `App.closeDocument(имя)` стирает данные восстановления
  (иначе при следующем запуске — «Document Recovery»), `QtWidgets.QApplication.instance().quit()` завершает
  приложение — закрытое главное окно на macOS его не завершает. Окно человека, открытое рядом, не трогай: по своему
  логу проверь, что скрипт отработал в своём процессе.
- Самопроверка видов: тот же таймер, `getattr(view, n)()` для `viewFront`/`viewLeft`/`viewRight`/`viewRear`/`viewTop`,
  `fitAll()`, `saveImage`. Деталь на дальней стороне или за соседним узлом на изометрии не видна — смотри с нескольких
  сторон и спроси себя, увидит ли человек то, о чём спрашивал, с камеры по умолчанию.
- Механизм проверяй в крайних положениях, а не в показанном: у каждой детали — метка, с какими осями она едет;
  копии подвижных сдвигаются на каждое сочетание концов ходов, пары с разными метками — отсев по `BoundBox` с запасом,
  потом `distToShape`; задуманные касания (каретка на рельсе, гайка на винте) — списком. Итог и отпечаток исходников
  пиши в `doc.Comment`: тест читает `Document.xml` из FCStd без FreeCAD и ловит и столкновение, и устаревший файл.
- Без окна проверяй модель так: пересечения деталей — `a.Shape.common(b.Shape).Volume`; виды — `TechDraw.projectToSVG`
  и `qlmanage -t` в PNG. Окно FreeCAD, запущенное из терминала, AppleScript `quit` не закрывает — гаси тем, чем
  запускал.
