# Стек: Python + FastAPI + MongoDB + Nuxt 3

Вариант общего стандарта (`stacks/python-fastapi-vue.md`) для контент-проектов, где вместо
Postgres — MongoDB, а вместо голого Vue — Nuxt 3 с SSR.

## Backend

- FastAPI + **motor** (асинхронный драйвер Mongo). Celery + Redis для фоновых задач
  и шедулера, `pydantic-settings` singleton для конфига, версии в `requirements.txt`
  запинены `==`.
- Структура: `app/api/` — роутеры (по одному файлу на домен + `router.py`, который их
  собирает в общий `api_router` с префиксом `/api`), `app/models/` — pydantic-модели,
  `app/services/` — бизнес-логика, `app/workers/` — Celery и шедулер, `app/parsers/` —
  внешние источники.
- Схемы в Mongo нет, поэтому строгость живёт в моделях ответа — и потому обязательна
  терпимость на чтении, см. `lessons/external-agent-data.md`.

## Frontend (Nuxt 3)

- **API проксируется через `routeRules` в `nuxt.config.ts`, а не через `devProxy`** —
  `devProxy` не работает для SSR-запросов, и это ловится не сразу: в браузере всё
  открывается, а серверный рендер молча ходит в никуда.
- Cookie при SSR пробрасывается вручную через `useRequestHeaders(['cookie'])`; функции
  стора, которым нужна авторизация на сервере, принимают опциональные SSR-заголовки.
- Pinia для состояния. Ошибка загрузки и пустой результат — **разные** состояния стора:
  `catch → items = []` даёт страницу, которая выглядит рабочей и отвечает 200.

## Проверки

- pytest с `asyncio_mode = auto`, отдельная тестовая БД, форсируемая в `conftest.py`
  **до** импорта приложения (иначе тесты вытрут рабочую базу), фейковый Redis, очистка
  волатильных коллекций после каждого теста.
- Тесты гоняются точечно по затронутым модулям (`tests/test_<модуль>.py`); полный пакет —
  перед деплоем, и его в любом случае прогоняет `make update` на сервере, прерывая деплой
  при падении. Полный прогон после каждой мелкой правки удлиняет цикл настолько, что
  проверки начинают пропускаться вовсе.

## Порты

Каждому проекту — своя сотня портов, чтобы несколько проектов поднимались одновременно
(например: фронт `x230`, бэк `x240`, БД `x270`, Redis `x279`).
