# Стек: kie.ai (генеративные изображения / видео / аудио)

- Auth: `Authorization: Bearer <key>`, `Content-Type: application/json`.
  Ключ — в настройках/БД (переопределяемо через админку), в чат/логи не выводить.
- Создание задачи: `POST {base}/api/v1/jobs/createTask` (у отдельных моделей свои
  пути, например Veo: `/api/v1/veo/generate`).
- **ГЛАВНАЯ ЛОВУШКА**: kie.ai отдаёт HTTP 200 с ошибкой в теле — всегда проверяй
  `body["code"]`: `code != 200` → это ошибка, поднимай исключение.
- **ЛОВУШКА №2 — текстовые модели (`/claude/v1/messages` и совместимые)**: не-стриминговые
  запросы с генерацией дольше ~2 минут гейтвей обрубает HTTP 500
  `api_error: Server exception, please try again later` (короткие проходят — это wall-time
  лимит, ретраями без стриминга не лечится; подтверждено 2026-07-24, 3 падения подряд).
  Всегда `stream: true` + сборка ответа из SSE-событий Anthropic-формата
  (message_start / content_block_delta / message_delta с usage и stop_reason);
  httpx-таймаут при стриме — пауза между чанками, не вся генерация.
  Транзиентные ошибки (5xx, api_error, overloaded_error) — один автоповтор с паузой.
- Результат: либо вебхук (в payload инжектится `callBackUrl`), либо поллинг
  `GET /api/v1/jobs/recordInfo?taskId=...` — статус в `data.state`: `waiting` →
  `success` / `fail` (живой API отдаёт `fail`, НЕ `failed` из доков — проверено
  2026-07-23); интервалы поллинга подбирать пер-модель. `resultJson` — СТРОКА
  с JSON (`{"resultUrls": [...]}`); URL результата временные — скачивать сразу.
- Аудио→текст (проверено 2026-07-24): быстрый путь — `gemini-3-flash`
  chat/completions с `input_audio` base64 (`format: "wav"`; webm НЕ поддержан),
  отвечает мгновенно. `elevenlabs/speech-to-text` (`input.audio_url`) жив, но
  очередь минутами и таймауты апстрима — только фолбэк.
- **Латентность LLM-конвейера = сумма выходных токенов** (2026-07-25): не
  генерировать один контент дважды (текст → ревью с переписыванием → конвертация
  формата = один документ трижды). Финальный формат (JSON) — сразу первым
  вызовом; ревью возвращает только вердикт+заметки; конвертация — редкий
  repair-фолбэк. Даёт ~3× ускорение без потери качества.
- Билдеры payload — по модели (dict-роутер `имя → _build_*`);
  httpx-таймауты на каждый вызов.
- Тяжёлые генерации — в фоновые задачи (Celery), не в обработчике запроса.
- Приоритетные модели для фото: nano banana 2, gpt image 2.
