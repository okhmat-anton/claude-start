# Целостность файлов, приходящих от платного API

Контекст: недокачанный видеофайл весил мегабайты, проходил проверку «размер > N» и валил сборку; исключение
внутри рабочего потока не попадало в счётчик, и пакет рапортовал «провалов: 0» при отсутствующем файле;
upload-эндпоинты отдавали пустое тело на крупных файлах. Платные генерации терялись молча.

Урок:
- Ретрай на самой передаче — и на скачивании результата, и на загрузке референса.
- Результат проверяй по существу: читаемость через probe длительности, а не размер.
- `try/except` вокруг тела рабочего потока, иначе исключение не считается провалом.
- Отдельный верификатор комплектности ассетов, который гоняется ПЕРЕД сборкой, — он же регрессионный тест на этот класс багов.
