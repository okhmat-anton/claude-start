# Список имён, собранный из id, обходит фильтр по id

Контекст: запрет движений по противопоказаниям снимал упражнения по id из кандидатов и пула замен, а замены каталога
и домашние замены шли готовыми именами — слепой судья нашёл «Скакалку» у подъёма на носки при запрете прыжков.

Урок:
- Где к одному множеству ведут два пути (id и имена, ключи и переводы, список и «готовые подсказки»), фильтр или вето
  применяется к обоим — лучше одной функцией, которая знает оба представления.
- Проверка — тест на побочном пути (замена, подсказка), а не только на главном пункте.
- Признак заранее: в коде есть «ручной» список строк рядом с вычисляемым из структуры.
