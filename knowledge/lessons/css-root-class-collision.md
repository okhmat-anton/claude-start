# Корневой класс нового компонента — сначала grep по стилям

Контекст: панель новой вкладки получила короткий класс, который в общей таблице стилей уже задавал сетку
«160px | 1fr» блоку другого раздела; вкладка разъехалась колонками, тесты зелёные — нашлось только по кадрам экрана.

Урок:
- перед тем как дать корневому элементу класс, сделай grep по всем таблицам стилей проекта (не только своего раздела);
- занятое имя не перекрывай — бери своё с префиксом компонента (`brief-pane`, а не `brief`);
- признак: короткое общее слово в имени класса и раскладка, которую ты не писал (grid, колонки, отступы).
