# Учёт времени и денег — из API, не из оценок

Контекст: реальная себестоимость ролика — wall-clock сессии (обсуждение, ожидание подтверждений) в разы больше
чистого времени генераций. Второй ролик серии обошёлся на четверть дешевле первого за счёт переиспользования.

Урок:
- По каждой задаче генерации API отдаёт фактические `costTime` и кредиты — суммируй по всем задачам ролика,
  включая отбракованные дубли.
- Отдельно фиксируй wall-clock сессии от первого действия до готового черновика.
- Веди накопительную базу по роликам: дата, рубрика, генераций принято/всего, время генераций, время сессии,
  кредиты, деньги, режим (ручной/автономный).
- Переиспользуй ассеты между роликами серии (якоря «до/после», энд-кард, треки) и спроси заказчика, не смущает
  ли повтор кадра в одной ленте.
