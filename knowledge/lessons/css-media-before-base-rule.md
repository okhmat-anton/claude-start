# Медиа-правило раньше базового той же специфичности действует частично — wrap без row; медиа-блоки после базовых, своему элементу свой класс

Контекст: мобильное правило карточки (`flex-direction: row; flex-wrap: wrap; justify-content: space-between`) стояло
в CSS раньше базового `flex-direction: column` той же специфичности. Направление осталось колонкой, а wrap и
space-between применились: в колонке с общей высотой сетки список завернулся во вторую колонку вправо, страница
стала шире телефона.

Урок:
- медиа-блоки держи после базовых правил той же специфичности: порядок, а не ширина экрана, решает, что применится;
- элемент с другим набором детей — свой класс со своим правилом, а не перекрытие чужого (карточка пакета ≠ карточка
  тарифа);
- «страница шире экрана» на телефоне ищи зондом в браузере (scrollWidth против innerWidth, элементы с правым краем
  за экраном), не рассуждением о CSS;
- признак: часть свойств медиа-правила видна в раскладке, часть «не сработала».
- выносишь одинаковые правила двух страниц в общий файл стилей — порядок меняется: общий файл, подключённый
  после стиля страницы, теперь перебивает её правила того же веса, что раньше шли после вынесенных (кнопка
  «включено» серела при наведении, ссылки снова подчеркнулись); такие правила страницы подними по весу (planning).
