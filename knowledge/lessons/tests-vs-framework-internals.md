# Тест проверяет то, что приложение отдаёт, а не то, как оно устроено внутри

Стек: любой проект на фреймворке, у которого запинена версия в образе.

## Ситуация

Смоук-тест «эндпоинт зарегистрирован» читал внутренний список маршрутов приложения.
Тест упал на живом приложении, где все маршруты работали: в свежей версии фреймворка
подключённые роутеры хранятся вложенными объектами-обёртками с пустым путём, а в
запиненной — плоским списком. Проверялась структура, а не поведение.

## Правило

Утверждение теста формулируется в терминах **наблюдаемого поведения**:

- маршруты — из схемы API (`openapi()`, `/openapi.json`), то есть из списка путей,
  которые сервис реально объявляет клиенту;
- ответ — из HTTP-статуса и тела, а не из внутренних атрибутов объекта;
- конфигурация — из того, как ведёт себя код при её значении, а не из содержимого
  внутреннего словаря настроек.

Признак плохого теста: он читает поле, которое не описано в документации фреймворка
как часть публичного интерфейса. Такое поле меняется в минорной версии без анонса.

## Версии локально и в образе расходятся молча

Второй источник этого падения — на машине разработчика стоит то, что подтянулось
последним, а в образ ставится запиненное. Расхождение не проявляется, пока тест не
упрётся во внутреннее устройство.

Следствия:

- зависимости для разработки держать **отдельным файлом** от рантаймовых, и ставить
  рантаймовые по запиненным версиям, а не «последнее подходящее»: свежая версия
  библиотеки-драйвера легко оказывается несовместима с запиненной обёрткой над ней
  (симптом — `ImportError` приватного имени, а не `ModuleNotFoundError`);
- проверять «модуль импортируется» по **пустому** выводу, а не по отсутствию строки
  `No module named`: `ImportError` из-за конфликта версий такую проверку проходит,
  и отчёт «всё импортируется» оказывается ложным.

## Что этот тест всё-таки должен ловить

Ради чего он писался: роутер, выпавший из сборки приложения, — не синтаксическая
ошибка. Ничего не падает до момента, когда клиент постучится по исчезнувшему пути
на проде. Тест на список объявленных путей ловит это на месте — при условии, что
смотрит на объявленные пути, а не на внутренности.
