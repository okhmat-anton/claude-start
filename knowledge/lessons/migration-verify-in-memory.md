# Импорт с перекрёстными ссылками — на настоящей выгрузке в базе в памяти дважды: числа не растут, ссылки разрешены, сводка сходится

Контекст: импорт сотен записей с перекрёстными ссылками (координаты, рубрики, сегменты, действия) проверен за
минуту на настоящей выгрузке в базе в памяти — до сервера и до ревью.

Урок:
- прогоняй импорт на настоящей выгрузке в базе в памяти дважды подряд;
- проверяй три вещи: числа на втором прогоне не выросли (отметка старого id у каждой записи), каждая ссылка
  разрешилась в новый id, сводка (чеклист, счётчики) сходится с данными старой системы;
- признак: перенос с внутренними ссылками между записями — без такой проверки висячие id всплывут у владельца.
