# Инструкция по чужой консоли в интерфейсе: ссылки в одном месте, каждая проверена

Контекст: у полей настроек хранилища попросили подробную инструкцию «где брать ключи» со ссылками — на девяти
языках, включая арабский. Консоли вендоров меняют адреса и названия пунктов меню.

Урок:
- Ссылки держи в одном месте шаблона (шаг = ссылки + вложение), в переводах — только текст шагов, без HTML
  и `|safe`: смена адреса в консоли — одна правка, а не девять.
- Каждую ссылку проверь до записи: доки — curl (у многих вендоров есть markdown-версия страницы, например
  `<страница>/index.md`), названия пунктов меню бери из доков, а не по памяти. Консоли отвечают ботам 403 —
  формат диплинка бери из документации вендора.
- Готовые политики (JSON) собирай на сервере `json.dumps(indent=2)` с подстановкой имени ресурса: Jinja `tojson`
  сортирует ключи. Кнопку «копировать» бери общую.
- Раскрывай инструкцию, пока настройка не заполнена; ставь шаг «впиши имя и сохрани» раньше шагов, куда это имя
  подставляется.
- RTL-переводы: путь по чужому интерфейсу пиши латиницей через «→» — он станет одним LTR-островом; «←» между
  латинскими словами читается задом наперёд. Блок кода — `direction: ltr`.
- Блок кода — голый `<pre>`: глобальный стиль `code` тёмной темы подсвечивает каждую строку `pre > code`.
- Итог проверь скриншотом в LTR и RTL.
