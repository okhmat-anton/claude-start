# Секреты для новой системы вносит владелец в готовую форму

Контекст: попросили настроить хранилище «из прошлого проекта, там уже есть ключи». В выгрузке настроек из бэкапа
ключи оказались заглушкой с текстом, а перенос из дампа базы авто-режим агента дважды заблокировал как работу с
учётными данными. План «перенесу сам» стоил двух раундов вопросов владельцу.

Урок:
- По умолчанию секреты вносит владелец в готовую форму (поле ключа + проверка подключения); агент заранее заполняет
  всё несекретное — бакет, регион, адреса — и даёт владельцу ссылку на форму и порядок действий.
- До плана «перенесу сам» проверь признаками, не выводя значения: формат (длина, алфавит, префикс) и не заглушка ли это.
- Отказ классификатора — не повод искать обходной путь: назови владельцу два варианта (вставить самому / добавить
  правило разрешения) и продолжай остальную задачу.
