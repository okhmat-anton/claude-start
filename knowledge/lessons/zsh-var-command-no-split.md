# В zsh команда в переменной ($CMD run …) не разбивается на слова и молча падает «command not found» — пиши команду целиком или массивом

Контекст: в цепочке команд инструмент вызывался через переменную (`LOOK="node …/look.js"; $LOOK run …`); zsh искал команду с пробелами в имени и падал в stderr, а `| grep -c png` показывал «0 кадров» без ошибки — два прогона стенда впустую.

Урок:
- в zsh незакавыченная переменная не разбивается на слова: команду пиши целиком или массивом `cmd=(node …); "${cmd[@]}"`;
- фильтруя вывод через grep, не глуши stderr — иначе падение выглядит как пустой результат;
- признак: вызов `$VAR …` после `VAR="прог аргумент"` и подозрительно пустой вывод.
