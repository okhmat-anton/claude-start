# Перед вторым потребителем платного потока (удержание → задача → опрос → хранилище → списание) вынеси поток в общий модуль с целями

Контекст: обложка альбома была первой генерацией картинок и держала весь платный поток (баланс → удержание →
задача → опрос → хранилище → списание) у себя; фото персонажа — второй потребитель того же потока.

Урок:
- Перед вторым потребителем вынеси поток в общий модуль с «целями»: папка в хранилище, запись итога, отметка отказа;
  цели регистрируются при старте (словарь «ключ параметра генерации → модуль»).
- Второй потребитель — только своя валидация и цель; тесты первого не меняются, фикстура «внешний мир» общая.
- Признак: копируешь функцию заказа с заменой одного поля.
