# Перерисовка возвращает :value — набранное исчезает

Контекст: кабинет перечитывает данные по событиям сервера. Поля с `:value` (без v-model, автосохранение) теряли
набранное при чужом событии; защита на пути «применить новые данные» помогла — а смена вкладки всё равно
стирала текст: Vue патчит `value` при каждой перерисовке компонента, не только при смене данных.

Урок:
- Запоминай «грязные» поля по событию input (значение, курсор, серверное значение) и восстанавливай их в
  глобальном хуке `updated` (`app.mixin`) — он ловит любую перерисовку.
- Сервер прислал другое значение того же поля — не выбирай молча: под полем строка «изменено агентом» с парой
  действий «сохранить моё» / «взять версию агента»; у автосохранения восстановление шлёт синтетический input.
- В самопроверку живых обновлений входят сценарии «печатаю, пока приходит чужое» и «переключил вкладку и вернулся».
- Родственное: ползунок с :value на сохранённое значение (vue-range-value-forced-patch) — тот же механизм патча.
