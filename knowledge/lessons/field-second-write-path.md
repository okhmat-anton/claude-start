# У поля одна дорога записи: своя ручка автосохранения и общая форма вместе обнуляют значение

Контекст: настройка получила свою карточку, которая сохраняется сразу по выбору отдельной ручкой, но осталась полем
общей формы настроек; «Save» общей формы слала поле пустым и сбрасывала выбор. Ревьюер увидел «настройка не
удержалась», я списал это на инструмент кадров — нашёл только упроститель по диффу.

Урок:
- Давая полю свою ручку, в том же коммите убери его из общей формы, её модели и обработчика: grep имени поля по
  шаблонам, страницам и роутам, а не только по сервису.
- Регрессия: «общий Save формы не меняет поле» — отправить форму без поля и проверить, что значение прежнее.
- Жалоба ревью «выбор не удержался» при зелёных тестах ручки — сначала ищи второй путь записи, потом вини инструмент.
