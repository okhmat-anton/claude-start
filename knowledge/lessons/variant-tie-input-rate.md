# Ничья в выборе варианта цены уводит на тариф «с входным роликом»

Контекст: Поставщик даёт два тарифа за секунду: «с входным роликом» дешевле (оплачиваются вход и выход) и «без ролика». Подбор варианта по разрешению давал им равные очки и брал первый — дешёвый.

Урок:
- исключай из выбора варианты для входов, которых заказ не подаёт (ролик, картинка на входе);
- регрессионный тест: на реальном каталоге выбранный вариант совпадает с входами заказа;
- цена ошибки — минус на каждом заказе при наценке меньше разницы тарифов.
