# Новые правила показывают на новых работах, а не на переделке старых

Контекст: правила генерации текстов ужесточили; в критерии готовности стояло «пять старых слабых текстов переписать,
было → стало». Владелец выбрал этот вариант кнопкой, а на первом же вопросе по тексту ответил «старое не
переписывать». Проверочный цикл «исполнитель в чистом контексте → слепой судья» и так дал свежие тексты по старым
и новым правилам на одних и тех же заказах — их хватило для показа.

Урок:
- Образцы для владельца — новые работы из проверочного цикла: одни заказы по старым правилам и по новым, с оценками
  судьи по осям. Это и доказательство, и показ.
- Переделку уже готовых работ в критерии готовности не закладывать — только по прямой просьбе: правила действуют
  на новое.
- Первый конкретный вопрос по спорному шагу задаётся до того, как на шаг опирается остальная работа: отмена тогда
  стоит одного ответа, а не часа.
