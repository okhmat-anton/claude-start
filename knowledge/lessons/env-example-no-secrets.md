# Секрет не кладётся в пример env-файла

Контекст: файл-пример лежит в git, значение секрета туда попасть не может. Скрипт деплоя, дописывающий
недостающие ключи из примера в рабочий env, при пустом ключе в примере перекрывает настоящее значение или
создаёт вторую строку.

Урок:
- В примере — только комментарий с именем переменной и указанием, откуда взять значение; сама переменная
  добавляется в рабочий env руками, один раз.
- Новая настройка backend — это две правки: поле в конфиге и строка в `environment:` нужного сервиса
  docker-compose (переменной, которой нет в списке, в контейнере не существует). Проверять ответом эндпоинта,
  а не тем, что контейнер перезапустился.
