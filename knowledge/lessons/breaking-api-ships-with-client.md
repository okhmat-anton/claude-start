# Несовместимый ответ API выходит только вместе с заменой клиента

Контекст: новый ответ списка перестал отдавать тела записей; старый клиент по «Обновить» отправил бы пустые
тела обратно и затёр бы данные — достаточно было выкатить бэкенд без нового фронта.

Урок:
- Изменение формы ответа, на которой держится запись в старом клиенте, коммить локально и выкатывай одним
  релизом с заменой клиента; до релиза — без push в ветку, из которой деплоят.
- Признак: старый клиент делает «прочитал → поправил → записал целиком» по этому ответу.
