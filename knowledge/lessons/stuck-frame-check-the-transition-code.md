# Замечание «заперт на экране» проверяй по коду перехода, а не только повтором кадра

Контекст: ревьюер записал блокером «после Back экран остался полупрозрачным, человек заперт». Кадр сняли в момент
анимации перехода. По коду «Back» вёл не в тупик, а на общий список ответов мастера — экран, которого человек,
пришедший править один ответ с другого экрана, не просил. Блокера не было, недоделка была рядом.

Урок:
- Замечание «подтвердить руками» разбирай по коду: куда на самом деле ведёт действие, — повтор кадра покажет только «не завис».
- У правки одного ответа, открытой с чужого экрана, «Назад» ведёт на этот экран; проверь каждый вход в общий мастер.
- Полупрозрачный кадр без кнопок — почти всегда середина перехода; сними второй кадр через секунду.
