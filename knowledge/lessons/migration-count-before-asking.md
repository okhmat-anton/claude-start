# Вопрос владельцу о переносе данных — сначала запрос к выгрузке: у какого проекта и в каком разделе лежат данные; в вопрос только проверенные числа

Контекст: владелец просил перенести данные старой версии «в этот проект», а в дампе они лежали у другого проекта;
в вопросе «куда переносить» агент по памяти написал «у остальных проектов в этих разделах пусто», а у одного была
запись — решение владельца опиралось на неверный факт.

Урок:
- перед вопросом о переносе посчитай запросом к выгрузке: какой проект, какой раздел, сколько записей у владельца;
- в вопрос пиши только числа из этого запроса — каждое «пусто / есть» проверено, а не вспомнено с прошлого взгляда;
- признак: просьба «перенеси данные из старой версии» с адресом проекта — данные часто лежат у соседнего проекта.
