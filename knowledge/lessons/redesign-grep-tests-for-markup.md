# Перед перерисовкой страницы grep тесты по её классам и переведи их на видимый текст; тест, упавший на структуре, чинится, а не разметка

Контекст: после перерисовки дешборда упал тест, который искал цифру через старые классы (`stat-value">3</div>`),
хотя цифра на странице осталась — сменилась только разметка.

Урок:
- перед перерисовкой страницы grep тесты по её классам и id и переведи проверки на видимый текст
  («Generations today: 3»), а не на структуру;
- тест, упавший на структуре при живой функции, чинится сам — разметку ради него не возвращают;
- крючки, которые тесты держат намеренно (id кнопок, классы меню), выпиши до правки и сохрани.
