# Новая настройка у автосохраняемых экранов — сохранять сразу

Контекст: новые поля легли в общую форму настроек под кнопкой «Save», а соседний экран той же задачи сохранялся
сам. Ревьюер привык к «оно само», ушёл без «Save» — выбор молча пропал, предупреждения не было.

Урок:
- в продукте с автосохранением новую настройку делай своей карточкой, которая сохраняется по выбору, с отметкой
  «Saved» рядом;
- поля без `name` внутри общей формы не уйдут её кнопкой — так карточка живёт на месте, а форма её не трогает;
- признак: на соседних экранах разные модели сохранения (кнопка и автосохранение) — потеря правок неизбежна.
