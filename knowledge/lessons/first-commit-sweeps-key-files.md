# Первый коммит нового проекта подметает файлы с ключами

Контекст: на первом коммите `git add -A` взял файл с ключом проекта планировщика и служебный файл версии, лежавшие рядом с кодом; заметили при проверке перед выкладкой.

Урок:
- До первого коммита — `git status` глазами и .gitignore на все служебные файлы владельца рядом с репозиторием.
- После — `git ls-files | grep` по именам ключей; ключ, попавший в историю, считается засвеченным — сказать владельцу.
