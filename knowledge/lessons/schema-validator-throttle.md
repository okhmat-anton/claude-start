# Валидатор разметки закрывает адрес после серии запросов

Контекст: Прогон 53 страниц через validator.schema.org оборвался на 37-й: дальше 405, потом 302 на любой запрос, часы без доступа.

Урок:
- страницы из одного шаблона проверяй одним экземпляром каждого типа с паузой 5+ секунд;
- полноту (типы, позиции, видимость вопросов) держи локальным тестом по всем страницам;
- сохраняй вывод прогона в файл сразу — после блокировки повторить нечем.
- замена валидатору без сети и лимитов — официальный словарь `schema.org/version/latest/schemaorg-current-https.jsonld`: сверка скриптом типов, полей, domainIncludes/rangeIncludes по цепочке родителей + обязательные поля Google; перед доверием — прогнать на нарочно сломанном образце.
