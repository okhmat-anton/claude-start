# Escape в модалке без preventDefault — браузерное «остановить загрузку» глушит следующее медиа: ролик после первого стоит на 0:00 (headless Chrome)

Контекст: Лайтбокс с видео на маркетинговой странице: первый ролик играл, каждый следующий стоял на 0:00 с полосой загрузки у нуля. Два круга ревью считали это поломкой; серверы, элемент, кодек и muted были ни при чём.

Урок:
- горячие клавиши модалок и лайтбоксов обрабатывай с `e.preventDefault()`: у Escape есть браузерное действие «остановить загрузку», и в headless Chrome оно глушит последующие медиа-запросы страницы;
- признак: «второй ролик не играет» воспроизводится только при закрытии клавишей, а крестиком — нет;
- цена: полтора часа гипотез (обрезка роликов, новый элемент, один формат) до бисекции способа закрытия.
