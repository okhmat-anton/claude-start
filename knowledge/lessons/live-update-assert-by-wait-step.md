# Живое обновление проверяется шагом ожидания, а не кадром

Контекст: нужно было доказать, что правка через API видна в открытой вкладке за секунду. Кадр «после» ничего
не доказывает — страница могла перезагрузиться; инструмент кадров идёт по сценарию и не ждёт внешних команд.

Урок:
- Сценарий: кадр «до» → шаг `wait text=…` с таймаутом → кадр «после». Внешняя команда (curl к API) ждёт появления
  файла кадра «до» и только тогда пишет — файл кадра служит сигналом синхронизации.
- Жди уникальный текст: ожидание «Changed by the agent» сработало мгновенно на старых пометках в списке; либо
  очисти состояние стенда, либо жди текст, которого на странице ещё нет.
- Отчёт шага ожидания («появилось: span… за N мс») и есть утверждение теста — храни его рядом с кадрами.
- Так же проверяются конфликт ввода (печатай в поле, потом пиши через API) и удаление открытой записи.
