# Список + панель без адреса открывает запись с последней активностью (updated_at или свежий дочерний элемент), а не самую новую по созданию

Контекст: в рабочем пространстве «список слева, панель справа» без адреса открывалась самая новая запись, а
человек ждал ту, над которой работал: вернулся с соседней вкладки — и попал не туда.

Урок:
- По умолчанию открывай запись с последней активностью: максимум из `updated_at` записи и `created_at` её
  свежего дочернего элемента (новая картинка, версия, запись); порядок списка при этом можно не менять.
- Признак: `rows[0]` как выбор «текущей» записи при сортировке по дате создания.
