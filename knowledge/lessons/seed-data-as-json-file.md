# Пробные данные стенда — файлом JSON, а не строками в zsh

Контекст: Сценарий засева слал тексты с «$15 → $50» из двойных кавычек zsh — суммы исчезли, записи ушли на сервер без них. Ревьюер видел обрывки фраз и мог записать их в поломки продукта; чинилось двумя лишними прогонами.

Урок:
- Пробные записи держать в JSON-файле и слать его curl -d @файл или из node/python — без подстановок оболочки.
- После засева один раз прочитать записи назад и сверить глазами ключевые тексты.
- Признак заранее: в пробных текстах есть $, обратные кавычки или восклицательные знаки.
