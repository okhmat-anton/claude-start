# Варианты одного экрана — общий composable с первого варианта, в компоненте только разметка

Контекст: макеты с тремя вариантами подачи на экран плюс вариант на библиотеке компонентов; каждая правка по итогам
ревью (обработчики, старт тренировки, итог дня) переписывалась в четырёх файлах, один из них забывался — ревьюер нашёл
кнопки без обработчиков.

Урок:
- общее для вариантов (состояние, переходы, действия по статусу записи, листы) — в composable с первого же варианта;
  компонент варианта — только разметка и свои стили;
- общие форматы строк (подзаголовок записи, подпись подхода, наборы вариантов выбора, вкладки) — в модуле данных,
  не в каждом варианте;
- признак: одинаковые `function start()` / `tap()` / `const FEEL = […]` в двух и больше файлах вариантов.
