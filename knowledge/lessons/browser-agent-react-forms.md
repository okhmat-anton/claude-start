# Агент заполняет кабинет на React: значение через событие, проверка по кнопке Save

Контекст: агент в браузере владельца заполнял App Store Connect по сценарию — девять языков текстов, анкеты,
подписки. Поля на React не видят значение, вписанное напрямую.

Урок:
- Значение ставь нативным сеттером value и событием input (bubbles), затем проверяй, что Save стал активным, а после
  сохранения снова погас, — иначе поле «заполнено» только на экране.
- Длинные тексты сверяй с файлом сценария по SHA-256, не на глаз: разные тире, кавычки «» и ’, огласовки арабского.
- Пункты меню выбирай по точному тексту («Add Ukrainian»), не координатами: соседние пункты стоят вплотную, и
  добавился соседний язык.
- Не уходи со страницы, где у владельца несохранённые правки (Save активен), — открой новую вкладку.
- В админках, где пустое поле при сохранении берёт значение из окружения, Save в пустой строке не нажимай.
- Ключи и пароли вставляет владелец; отправка на проверку, выпуск и подпись договоров — только он. В сценарии у
  каждого шага — «уже сделано?»: часть мог сделать он сам.
- Итог агента — файл «что настроено и чем кабинет отличается от сценария» рядом со сценарием: из него правится шаблон.
