# Сгенерированный текст — не носитель правил и не носитель метаданных

Контекст: доменные правила из документации и журналов не влияли на генерацию, пока не попали в промт;
промт-ревьювер пропускал всё, что описано расплывчато. Требование «все величины в предпочитаемой единице» ИИ
выполнял для ЧИСЕЛ, а подпись локализовал под язык ответа — число в фунтах с подписью «кг»; парсер вытаскивал
единицу регексом и пересчитывал величину ещё раз.

Урок:
- Правило существует для ИИ только текстом в промте. Ревьювер («квалити-гейт») работает только по явному
  перечню «REVISE, если …», не по общим пожеланиям.
- Метаданные (единица, валюта, пояс) фиксируй в структуре рядом с данными на момент записи и считай источником
  истины; суффикс в тексте — только фолбэк для старых записей.
- В промте отдельным пунктом требуй канонический вид подписи (латиницей, из закрытого списка), иначе ИИ её переведёт.
