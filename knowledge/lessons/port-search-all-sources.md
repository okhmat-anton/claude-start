# Перенос из прошлого проекта — искать во всех соседних репозиториях

Контекст: владелец попросил «вытащи протоколы из прошлого проекта». Поиск шёл только в названном
репозитории-доноре; видеопротоколы нашлись в соседнем рабочем репозитории после поправки владельца «там точно
были протоколы как делать видеоролики».

Урок:
- Перенос «из прошлого проекта» начинай с поиска по всем соседним репозиториям владельца по именам артефактов
  (`*Protocol*.md`, `*AGENTS*.md`, `CLAUDE.md`, папки `protocols/`, `aiProtocols/`), а не только в доноре из
  документации: владелец помнит артефакты, а не репозиторий, где они лежат.
- Покажи владельцу найденную карту источников (что, где, сколько) до переноса — пропуск виден сразу.
- Несколько версий одного артефакта в разных репозиториях — это конфликт для слияния, а не выбор одной.
