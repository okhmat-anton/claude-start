# На пути создания свободный текст не обязателен: пустому значению — смысл (нейтральный вариант), а не отказ «сначала опишите»

Контекст: поле «что нарисовать» было обязательным: у новой записи без описания кнопка молчала, подсказка обещала
«первое рисуется по описанию», а пустое поле давало отказ — ревью: «путь обрывается на первой же записи».

Урок:
- На пути создания не делай свободный текст обязательным: дай пустому значению смысл (нейтральный вариант по
  умолчанию) и скажи об этом в подсказке поля.
- Отказ «сначала опишите» и приглушённая кнопка без причины — тупик для новичка; код отказа тогда не нужен вовсе.
- Признак: обязательное текстовое поле, которое заполняется из другого необязательного поля.
