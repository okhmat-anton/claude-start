# Событие датируется своим моментом, а не updated_at

Контекст: журнал «что произошло» датировал «скрыта» по `updated_at`. Любая правка скрытой записи (фото, заголовок)
переносила «скрытие» на эту минуту, склеивала строки и выдавала чужие действия за новые.

Урок:
- Действие, которое показывается в журнале, пишет своё поле времени в момент действия (`hidden_at`) и автора.
- Повторное то же действие время не сдвигает (в обновлении — «оставить, если уже в этом состоянии»).
- Старые записи без поля в журнал не попадают: лучше промолчать, чем назвать неверное время.
