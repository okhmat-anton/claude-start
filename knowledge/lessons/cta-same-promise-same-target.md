# Провёл выбор через регистрацию — все кнопки с тем же обещанием ведут на тот же адрес с параметрами; grep по CTA

Контекст: Выбор тарифа или пакета на сайте проводился через регистрацию параметром; четыре кнопки довели выбор до кабинета, пятая с тем же текстом вела на голую регистрацию и в пустой дешборд с нулём токенов.

Урок:
- провёл выбор через регистрацию или вход — grep все кнопки и ссылки с тем же обещанием и дай каждой тот же адрес с теми же параметрами;
- проверь путь каждой кнопки кадром до кабинета, а не только первой;
- признак: несколько CTA с одинаковым текстом в разных блоках страницы.
