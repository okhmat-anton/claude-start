# Редактор с историей отправляет только изменённое

Контекст: редактор отправлял всю форму. Сервер приводил нетронутые поля к своей форме (все языки, без лишних
ключей), история после правки одного заголовка писала «изменено: текст, фото, источник», а лишние поля, присланные
другим клиентом, пропадали.

Урок:
- Сохранение шлёт разницу с загруженным состоянием; сравнивай по тем же полям, что хранит сервер.
- Признак «есть несохранённые правки» считай тем же сравнением — тогда он гаснет ровно после сохранения.
