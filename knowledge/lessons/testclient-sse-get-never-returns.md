# GET на SSE-поток под TestClient не возвращается, а вывод скрипта в конвейере буферизуется — зависание выглядит как молчание

Контекст: эталонный скрипт проверял сервер через TestClient и «завис» на 120 секунд без единой строки вывода. Причина —
последний шаг делал GET на адрес, который открывает бесконечный SSE-поток; печать предыдущих шагов не дошла до экрана,
потому что stdout в конвейере `| grep | tail` буферизован.

Урок:
- GET на адрес с `text/event-stream` под TestClient не делай; проверяй потоковым клиентом с таймаутом
  (`httpx.Client.stream(..., timeout=3)`) и закрывай.
- Скрипт, вывод которого идёт через конвейер, запускай `python -u` — иначе место зависания не увидеть.
- Признак: «завис» без единой строки вывода при наличии print до подозрительного шага.
