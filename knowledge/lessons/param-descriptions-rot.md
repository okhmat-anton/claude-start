# Описания параметров протухают вслед за моделью

Контекст: описание врёт молча — тесты его не проверяют, а пользователь принимает по нему решения. Нормировка
величины незаметно превратила параметр «сила эффекта» в параметр «форма эффекта», а текст обещал прежнее поведение.

Урок:
- Меняя модель, тем же движением проходи по описанию каждого входа и каждой метрики и сверяй КАЖДОЕ утверждение с кодом.
- Первые кандидаты на протухание: числа внутри текста (размер сетки, порог, единица) и обещания про поведение,
  которое модель перестала иметь («ниже границы ничего не происходит» после нормировки).
- Нормировка особенно опасна для описаний: сначала переписывай текст, потом нормируй.
