# Тесты в общей базе сессии смотрят только на свои данные

Контекст: схема тестовой базы создаётся один раз на сессию, записи между тестами не чистятся. Лента стала показывать
посты всех открытых людей, порядок сменился на «по времени» — и упали тесты «вся лента — посеянные посты», «друзья —
ровно один», «удалено ровно 30», но только при другом порядке файлов. Два файла регистрировали одну почту:
регистрация существующей почты входила в тот же аккаунт, тесты молча делили человека.

Урок:
- тест проверяет только свои записи: фильтр по своим id и никам, а не «всё, кроме меня»;
- почта и имена в тестах уникальны на весь набор, не одна «fan@…» в двух файлах;
- тест, который ставит глобальный признак (демо, владелец, флаг), возвращает его в конце;
- после правки, которая расширяет выборку (лента для всех, поиск шире), прогони набор в обратном порядке файлов:
  `pytest $(ls -r tests/test_*.py)` — зависимость от порядка видна сразу;
- признак: тест зелёный один и красный в наборе.
