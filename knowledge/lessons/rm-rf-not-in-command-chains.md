# rm -rf не ставится в составные команды

Контекст: цепочка «правка → рестарт стенда → сценарий» начиналась с `rm -rf` каталога кадров во временной папке;
защитный хук не признал путь временным и заблокировал команду целиком — ни правка, ни сценарий не выполнились.

Урок:
- Под защитным хуком `rm -rf` — только отдельной командой, если он вообще нужен; в цепочках заводи новую папку с
  суффиксом (`out-2`), а не чисти старую.
- Результаты прогонов с именем по номеру круга и так полезнее: старые кадры остаются для сравнения.
