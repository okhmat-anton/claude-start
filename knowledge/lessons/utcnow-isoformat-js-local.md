# Время без смещения браузер читает как местное — подпись правки уезжает на пояс

Контекст: ручка сохранения отдавала `datetime.utcnow().isoformat()` — строку без `+00:00`; `new Date(str)` в браузере
разобрал её как местное время, и подпись «изменено» показывала правку на несколько часов вперёд. На сервере с TZ=UTC
незаметно, на ноутбуке видно с первого кадра.

Урок:
- В ответах API время только со смещением: `datetime.now(UTC).isoformat()` даёт хвост `+00:00`; наивный `utcnow()`
  (к тому же объявлен устаревшим) в JSON не отдавай.
- Регрессия на ручку: `assert body["updated_at"].endswith("+00:00")`; на фронте строку даты без зоны считай ошибкой данных.
- Признак заранее: время на кадре стенда отличается от часов машины ровно на часовой пояс.
