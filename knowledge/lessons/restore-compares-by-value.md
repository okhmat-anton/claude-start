# Восстановление снимка не должно запускать «сбросить зависимые»

Контекст: «Назад» в правке ответа анкеты возвращал снимок ответов через `Object.assign`; список упражнений приходил
новым массивом с тем же содержимым, наблюдатель «упражнение поменялось → вес цели спросить заново» сравнивал по ссылке
и стирал вес цели. Любая отменённая правка тихо теряла цель.

Урок:
- Наблюдатели «ответ поменялся — сбросить зависимые» сравнивают значения (`JSON.stringify` или глубокое сравнение),
  а не ссылки; восстановление того же содержимого — не изменение.
- Проверка — кадр экрана ответов после «Назад» из правки: зависимые ответы на месте.
- Признак: `watch(() => answers[id], (v, old) => v !== old && …)` рядом с откатом через снимок.
