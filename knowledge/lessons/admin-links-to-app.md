# Админка всегда со ссылкой на приложение

Контекст: владелец попросил отдельной задачей добавить в админку ссылку на приложение и сделал это правилом для всех
проектов: из админки в приложение — в один клик.

Урок:
- Делая админку, сразу ставь в её меню пункт «Приложение» на корень приложения (с сессией пользователя он ведёт
  в кабинет, без неё — на вход); подпись — через словарь, как весь интерфейс.
- Обратный путь — кнопка «в админку» в кабинете: только для админской сессии и только серверным рендером, чтобы адрес
  админки не попадал в разметку остальных пользователей.
- Админка и приложение на одном домене — ссылка относительная; на разных — от настройки базового адреса, не строкой.
- Закрепи тестом: в рамке каждого раздела админки есть ссылка на приложение.
