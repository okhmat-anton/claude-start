# Сетка с неразрывной строкой распирает страницу на телефоне — min-width: 0

Контекст: строка вкладок без переноса (прокрутка вбок) внутри колонки CSS-сетки: на телефоне колонка стала шире
экрана и обрезала текст справа. На компьютере не видно — поймали только кадры телефона.

Урок:
- Детям сетки и flex-контейнера, внутри которых есть прокручиваемая строка или таблица, ставь min-width: 0 —
  иначе минимальная ширина ребёнка равна ширине его содержимого.
- Таблицы на телефоне — в обёртку с прокруткой вбок и минимальной шириной, а не в сжатую сетку.
- Кадр телефона проверяй на обрезанный правый край отдельно от «всё на месте».
