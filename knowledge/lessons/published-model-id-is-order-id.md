# Публикуемый id модели — тот, которым её заказывают

Контекст: Пару «картинка → картинка» сервис запускает сам, когда к модели «текст → картинка» приложены образцы; свой id пары серия не принимала и молча брала модель по умолчанию.

Урок:
- держи одну функцию «что заказываем и каким id» и бери id для документации и сайта из неё;
- у пары показывай id для заказа и как её включить (приложить образцы);
- признак ловушки: «незнакомое значение → значение по умолчанию» без ошибки.
