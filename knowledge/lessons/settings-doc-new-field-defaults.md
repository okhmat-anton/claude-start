# Новое поле вложенных настроек: сохранённый документ перекрывает умолчания

Контекст: в список пакетов умолчаний добавили поле скидки, а в базах стенда и прода уже лежал документ со старым
списком — он перекрыл умолчания целиком: скидки везде 0, ошибок нет, интерфейс просто не изменился.

Урок:
- Новое поле элемента вложенного списка настроек — сливай при чтении по id: `{**default, **saved}`, а не
  документ целиком; сохранённые значения побеждают, недостающие берутся из умолчаний.
- Регрессионный тест: сохранённый документ без нового поля → чтение отдаёт значения из умолчаний.
- Признак заранее: настройки читаются как «умолчания, обновлённые документом» (`dict(DEFAULT); update(doc)`) —
  любое новое поле внутри списков не доедет до существующих баз.
