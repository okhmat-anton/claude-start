# Пункт закрытого списка обрезается: имя короткое (без хвоста каталога), единица — в подписи поля, в пункте — только число

Контекст: пункты списка «2 — 20.8 tokens» и «Vendor - Model Name · 10.4 tokens» обрезались в закрытом `select` на
телефоне (видно «20.8 t»), а имена моделей из каталога поставщика («… - Text to Image») не влезали никуда.

Урок:
- Имя для списка делай коротким на сервере (срежь хвост вида «Text to Image» и дефисы-разделители каталога),
  единицу измерения вынеси в подпись поля («Model · tokens»), в пункте оставь только число.
- Длинное поле — во всю ширину, короткие — по два в ряд; подпись поля тоже должна влезать в полуширину.
- Признак: пункт `select` длиннее ~16 символов при полуширине на телефоне.
