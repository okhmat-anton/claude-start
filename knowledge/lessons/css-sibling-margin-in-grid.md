# Соседние отступы (`.card + .card`) в сетках — выключать по родителю единым списком

Контекст: правило `.card + .card { margin-top }` с исключениями для двух классов сеток не знало про третью, новую
сетку — второй элемент каждого ряда сползал на 16 px, ревью увидело «карточки вразнобой».

Урок:
- Отступ между соседями (`* + *`, `.card + .card`) в сетке и flex-ряду отключай одним селектором по родителю:
  `.grid > .card + .card, .card-grid > .card + .card { margin-top: 0 }` — единый список исключений в одном месте.
- Новая сетка или ряд карточек — новый пункт в этом списке и кадр с двумя элементами в ряду: один элемент дефект
  не покажет.
- Признак: карточки в ряду на разной высоте, второй ниже первого ровно на величину отступа.
