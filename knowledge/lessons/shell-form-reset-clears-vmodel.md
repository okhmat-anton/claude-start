# Оболочка сбрасывает форму после ответа — при повторном открытии окна с отказом верни значение в поле руками, v-model сам не восстановит

Контекст: оболочка одностраничного кабинета после ответа сервера закрывает диалог и сбрасывает формы «добавить»
(`form.reset()`); при повторном открытии окна с отказом поле ссылки оказалось пустым, хотя состояние хранило
значение — Vue не перерисовывает input, пока само состояние не изменится.

Урок:
- Если оболочка сбрасывает форму, при повторном открытии диалога верни значение в поле руками
  (`input.value = state`) сразу после `showModal()`, а не полагайся на `v-model`.
- Признак: в оболочке есть `form.reset()` по шаблону адреса, а страница хранит введённое в реактивном состоянии.
