# Просьба доработать описание задачи — это сама работа, а не повод спросить про техзадание

Контекст: владелец написал «доработай описание задачи — задай вопросы, если надо» и получил подряд два служебных
вопроса: уровень задачи и «оформить ли постановку техзаданием?». Ему пришлось дописать «но перед этим доработай
описание задачи» — второй вопрос повторял его просьбу другими словами.

Урок:
- Просьба доработать описание или постановку — ответ на вопрос о техзадании уже дан: дорабатывается заметка
  владельца на месте (его исходные слова сохраняются внизу файла), вопросы — только по сути задачи.
- Служебный вопрос, который повторяет просьбу владельца другими словами, не задаётся; обязательный вопрос об уровне
  остаётся.
- Признак: владелец отвечает на служебный вопрос текстом и повторяет исходную просьбу.
