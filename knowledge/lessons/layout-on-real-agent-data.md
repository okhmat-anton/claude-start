# Вёрстку справочника проверять на настоящих данных агента

Контекст: таблица справочника на коротких пробных значениях выглядела аккуратно и прошла два круга ревью.
Настоящая база, собранная агентом, пришла абзацами с цифрами и ссылками на источники: ячейки по двадцать
строк, колонки за краем экрана. Увидели только после загрузки настоящих данных на стенд.

Урок:
- Перед ревью экрана, который показывает вывод агента, положить на стенд настоящий вывод или образец той же
  длины и с теми же ссылками.
- Поля длиннее строки — карточкой со сворачиванием: название и главная мысль на виду, подробности по нажатию;
  ссылки источников нажимаемые и подписаны адресом сайта.
- Признак заранее: в формате, который даёт агенту протокол, поля без ограничения длины.
