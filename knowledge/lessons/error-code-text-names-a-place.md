# Общий код ошибки несёт текст про другой экран — новому сценарию свой код

Контекст: новый платный поток (картинка) собрали на кодах отказа соседнего потока (музыка). Код «нет идеи» подошёл
по смыслу, но его текст для человека говорил «добавьте текст на вкладке „Текст“» — про другой экран.

Урок:
- Заводя новый сценарий на общих кодах ошибок, прочитай тексты этих кодов во всех словарях, а не только имена:
  текст называет место, кнопку или предмет другого сценария — заводи свой код и свой текст.
- Признак заранее: код пишется в стиле «нет X», а X в новом сценарии называется иначе или живёт на другом экране.
- Цена: человек читает инструкцию, которую нельзя выполнить, и считает интерфейс сломанным.
