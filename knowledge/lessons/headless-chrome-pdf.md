# Печать в PDF через Chrome без окна: признак готовности и сжатие всего документа

Контекст: документы собираются из HTML печатью Chrome без окна. Chrome иногда не выходит сам, поэтому
готовность ловят по содержимому файла («%%EOF» в конце), а обложка задана на всю страницу без полей.

Урок:
- Удаляй прежний PDF до запуска печати: старый файл на том же месте проходит проверку «%%EOF» раньше,
  чем Chrome начнёт писать новый, и наружу уходит вчерашний документ. Признак — размер файла не меняется
  между прогонами.
- Любой элемент шире колонки (украшение ::after у последнего шага в строке, запрет переноса в заголовке
  таблицы) заставляет Chrome молча ужать ВСЕ страницы. Признак — белая кромка справа и снизу у обложки без
  полей. Ищи, что торчит за край, и режь overflow:hidden у украшений.
- Виновника называет программа, а не глаз: скрипт страницы после отрисовки ищет элементы, чей правый край
  дальше края колонки (и ни один предок их не обрезает), и пишет их через console.log. Chrome с флагами
  `--enable-logging=stderr --v=0` отдаёт журнал страницы в stderr — направь его в файл (не в поток: помощники
  Chrome держат поток открытым после печати) и разбери строку. Нашлось — такой PDF не отправлять.
- Готовый PDF проверяй страницами-картинками (pdftoppm, 60–70 точек на дюйм, все страницы одним листом):
  полупустые страницы, наложенные подписи и хвосты таблиц видны только так. Нет pdftoppm — сборка должна
  остановиться с подсказкой, как его поставить, а не молча пропустить проверку.
- Широкие таблицы (10+ столбцов) — на альбомный лист через именованную страницу (@page wide + page: wide),
  а не мелким шрифтом.
- Заголовку раздела — `break-inside:avoid` вместе с `break-after:avoid`: одного второго мало, двухстрочный
  заголовок режется пополам между страницами. Подписи перед таблицей или списком — `break-after:avoid`
  (`p:has(+ table)`), иначе она остаётся одна внизу страницы, и `break-inside:avoid` — иначе короткий
  абзац из двух строк рвётся между страницами. Таблицам перенос не запрещать: шапка
  повторится сама, а запрет даёт пустую треть страницы.
