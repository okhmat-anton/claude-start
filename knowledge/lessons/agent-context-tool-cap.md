# Инструмент-контекст для чат-агента — под потолок ответа инструмента

Контекст: Инструмент собирал для чат-агента всё разом: настройку, брифы проектов, доски задач, документы, прошлые списки. Сервер режет каждый ответ инструмента до фиксированного числа знаков с головы; на живых данных протокол и карта проектов до модели не дошли бы. Поймало ревью кода, не прогон: на стенде данные крошечные.

Урок:
- У инструмента, который отдаёт контекст одним ответом, свой потолок в таблице потолков (выше общего), а сам ответ ужат лимитами на каждый кусок (бриф, число задач, комментариев, прошлых записей, длина строк).
- Протокол и настройки — раньше данных: если резать с головы, под нож уходит хвост.
- Размер закреплён проверкой на тяжёлой фикстуре (максимум проектов, десятки задач с длинными описаниями, десять дней по десятки записей) в общем прогоне проверок.
- Подробности агент добирает отдельными инструментами по одному объекту.
- Признак заранее: инструмент собирает данные из нескольких разделов и возвращает массивы без лимитов.
