# Проверка кода существует только у правила, написанного модели в промте

Контекст: цепочка «писатель → проверки кода → судья → доработка». Проверка «день полупустой» спорила с правилом школы
«тестовый день короткий»; проверка языка считала английскую подсказку каталога ошибкой, хотя экран переводит её
словарём; слово «bar» ловило турник, «calf raise» — ступеньку. Каждое ложное срабатывание — лишний круг модели за
деньги и минуты ожидания человека.

Урок:
- Заводи проверку кода только у правила, которое уже написано модели текстом, и возвращай заметку словами того же
  правила — иначе писатель чинит не то.
- Исключения бери из самого протокола (тестовый день, возврат после перерыва, школа с короткими сессиями, словарь
  переводов), а не из догадок о «нормальной» тренировке.
- Новую проверку сначала прогони по сохранённым результатам прошлых циклов и посмотри, что она сняла бы; в бой —
  после этого.
- Признак: судья школы и проверка кода требуют противоположного на одном черновике.
