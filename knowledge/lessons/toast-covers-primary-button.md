# Всплывающая строка не ложится на главную кнопку

Контекст: строка «сохранено / готово» появлялась над нижней панелью — там, где у экрана подвал с главной
кнопкой; несколько секунд кнопка была закрыта, клик уходил в строку. Правило стиля для этого было, но с
предком, которого у строки нет, — оно ни разу не действовало.

Урок:
- Место всплывающего элемента проверяй в трёх состояниях: экран без подвала, с подвалом, с открытым листом
  (там строку уводи наверх).
- Правило CSS с предком проверяй в браузере — совпал ли селектор, — а не чтением стилей.
- Сценарий стенда «не нашёл кнопку» после действия со строкой — сначала посмотри кадр: кнопку могло закрыть.
