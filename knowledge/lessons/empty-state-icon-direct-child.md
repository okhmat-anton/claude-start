# Большая иконка блока (пустой экран) — только прямой потомок: .empty > i, иначе иконки кнопок внутри раздуваются

Контекст: Правило большой иконки пустого экрана (`.empty i { font-size: 48px; display: block }`) цепляло иконки кнопок внутри того же блока — кнопки раздувались до 100 px; увидел владелец в проде.

Урок:
- стили «большой иконки блока» пиши только для прямого потомка (`.empty > i`), а не для всех вложенных;
- добавил кнопки с иконками внутрь блока с крупной иконкой — сними кадр пустого состояния;
- регрессия — тест на наличие `>` в правиле.
