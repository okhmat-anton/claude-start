# «Сейчас» читается один раз на всю проверку

Контекст: очередь отложенной отправки сравнивала свой `now` с `max(_now(), …)` из функции «когда можно» —
второе чтение часов на микросекунды позже, и «интервал не прошёл» было правдой всегда. Месяцы ни одна
запись не ушла, все истекли; тесты проверяли только «ждёт».

Урок:
- Функция «готово ли / когда можно» принимает `now` от вызывающего; внутри часы не читает.
- К тесту «ждёт» всегда пара: «ничего не мешает → уходит сразу».
- Признак беды: в журнале только «истекло», ни одного «отправлено».
