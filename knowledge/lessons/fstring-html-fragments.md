# Генерация HTML f-строками: условные фрагменты — в переменные; \" внутри {…} вложенной f-строки ломает синтаксис

Контекст: генератор статических страниц на f-строках дважды падал с «unexpected character after line continuation
character»: условные куски разметки писались вложенной f-строкой, и экранированные кавычки \" попадали внутрь
выражений {…} — там backslash недопустим даже в Python 3.12, хотя те же кавычки во вложенной строке уже разрешены.

Урок:
- Условный фрагмент разметки считай в переменную до f-строки (`chip = '…' if x else ""`), а в f-строку подставляй
  только имя; вложенные f-строки держи без backslash в выражениях.
- Признак заранее: `{…\"…}` или `{f"…{a[\"k\"]}…"}` в строке — компиляция упадёт; проверяй `python -c "import ast;
  ast.parse(open(f).read())"` сразу после записи файла, не при запуске.
- Массовую правку таких мест делай по одному уникальному якорю с проверкой «ровно одно совпадение».
