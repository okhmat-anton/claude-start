# Крошечные миниатюры в сетке: браузерный отступ figure (1em 40px) — margin:0 на сам класс тайла, не на контейнер

Контекст: `<figure class="tile">` в сетке колонок по 130 px рисовал видео шириной 50 px — браузерный отступ figure
(1em сверху-снизу, 40px по бокам) съел ширину; сброс `margin: 0` стоял только у одной из стен, а тайл живёт в пяти местах.

Урок:
- `margin: 0` вешай на сам класс компонента-тайла, а не на контейнер, где он встретился первым;
- элементы с браузерным отступом (figure, fieldset, dl, blockquote) сбрасывай в момент, когда делаешь их компонентом;
- признак: миниатюры одного размера в одной сетке и разного — в другой при одном классе.
