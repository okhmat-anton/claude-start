# Инструмент кадров ревью не выбирает пункт родного select

Контекст: сценарий ревью на стенде должен был сменить выпадающую настройку и проверить, что она держится; шаг
«select» инструмента выделяет текст на странице, а стрелки с Enter в родном списке в headless Chrome дают случайный
пункт. Ревьюер принял это за поломку страницы и снял балл.

Урок:
- Родной `<select>` рисует браузер, DOM-кликами его не открыть; стойкость выпадающей настройки проверяй так:
  значение через API стенда → кадр → «Save» общей формы → уход на другую страницу и возврат → кадр и GET через API.
- В бриф ревьюеру одной строкой: «выбрать пункт выпадающего списка инструмент не умеет — это не замечание к странице».
- Нужен настоящий выбор в сценарии — ставь значение скриптом: `el.value = …; el.dispatchEvent(new Event('change'))`,
  а не клавишами.
