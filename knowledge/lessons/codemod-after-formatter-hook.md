# Скрипт замен при хуке-форматере: перечитай файл перед запуском, правь блок целиком между маркерами, скрипт идемпотентный — упавший посередине оставляет полуправку

Контекст: скрипты замен по строковым якорям трижды падали посреди работы: хук-форматер переписал якорь (разбил вызов
на строки, добавил пробел в срез) между прогонами; один скрипт вставил импорт в первое вхождение общего префикса —
внутрь функции — и сломал файл тестов.

Урок:
- Перед скриптом замен перечитай файл в текущем (отформатированном) виде; якорь — полная уникальная строка, не префикс.
- Блок правь перегенерацией целиком между уникальными маркерами-комментариями, а не десятком якорей.
- Скрипт делай идемпотентным (проверяй «уже применено», не падай на первом промахе): упавший посередине оставляет
  полуприменённое состояние, которое тесты могут даже пройти.
