# Стенд ревью возвращает состояние входа при каждом перезапуске

Контекст: субагент-ревьюер в сценарии «сменить пароль» сменил пароль пользователя стенда и наделал неудачных входов;
следующий круг не смог войти по сохранённым реквизитам (401, потом блокировка), а кадры молча не снялись — отчёт
инструмента пришёл пустым, без шагов.

Урок:
- Запуск стенда с сохранением данных заново ставит пароль пользователя из файла реквизитов и снимает блокировки
  входа: ревью вправе менять всё, а следующий круг обязан войти.
- Пустой отчёт без шагов — не баг приложения: сначала `curl` формой входа по файлу реквизитов, потом искать дальше.
- Сценарии, меняющие реквизиты (пароль, почта), — на отдельном пользователе или последними в круге.
