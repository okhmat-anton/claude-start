# Референс стиля — фрагмент без предмета и позы

Контекст: постер-референс для модели картинок заставлял повторять «прыжок со штангой» при явном запрете в промте;
вырезанный из того же постера фрагмент без фигуры (блины, искры) дал стиль без позы.

Урок:
- для стиля давай модели кусок референса без предмета и без фигуры; предмет и поза — только словами;
- у модели картинок референс сильнее промта: запрет «не повторяй позу» не работает;
- признак: на трёх вариантах подряд одна и та же композиция референса.
