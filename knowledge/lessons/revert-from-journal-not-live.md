# Откат ищет снимок в журнале, а не сущность среди живых

Контекст: Маршруты истории и отката начинались с поиска записи среди живых и отвечали 404 для удалённой. Журнал прилежно писал снимок при удалении, но вернуть его было нельзя. Поймал архитектурный ревьюер по закрытому списку правил, не разработчик.

Урок:
- История и откат читают журнал по идентификатору записи; живую сущность ищут только чтобы решить, править её на месте или создавать заново из снимка.
- Откат на занятое место (та же дата, тот же уникальный ключ) — 409 с понятной причиной, а не второй объект.
- Закреплять проверкой «создал → удалил → история видна → откат вернул» через маршрут, не только через функции модуля.
