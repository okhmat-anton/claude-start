# Ключ словаря — из кода, не из слова языка

Контекст: `t('common.weekday.' + короткое имя дня)` — имя дня бралось из `Intl` на языке человека («пт»), и экран
показывал сырой ключ `common.weekday.пт`. По-английски «fri» совпадало с ключом — на языке разработки ошибки не видно.

Урок:
- Ключи словаря собираются только из стабильного кода (mon…sun, kind, id), никогда из вывода `Intl` или словаря.
- Проверка — кадр экрана на втором языке, не на языке, на котором писали.
- Признак: `t(prefix + format(...))` или `t(prefix + t(...))`.
