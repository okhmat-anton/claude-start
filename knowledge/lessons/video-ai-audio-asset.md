# Звук ИИ-клипов — актив, а не мусор

Контекст: i2v-модели с аудио возвращают синхронный саунд-дизайн (щелчки, шаги, whoosh переходов). Наложение
библиотечной копии поверх тихого родного звука дало слышимое эхо, которое ловят только уши заказчика.

Урок:
- Не собирай ролик с `-an`: родной звук синхронен с картинкой идеально.
- Тихий родной звук лечи усилением сегмента (`volume=N,alimiter`), не наложением копии со сдвигом.
- Полезные звуки вырезай в библиотеку проекта (`loudnorm=I=-14:TP=-1.5`) для случаев, где родного звука нет.
- Момент звука ищи численно: RMS по окнам 0.1 с (декодировать `-f s16le`) — сразу видно секунду щелчка.
