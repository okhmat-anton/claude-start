# Результат задачи поставщика разбирать по типу носителя (картинки, звук, видео отдельными списками), не по расширениям картинок — иначе mp4 теряется

Контекст: разбор ответа задачи отбирал ссылки по расширениям картинок; `.mp4` из списка результатов отбрасывался, и
успешная видеозадача приходила с пустым результатом — обработчик доставки считал её отказом и возвращал токены.

Урок:
- Разбирай результат по типу носителя: отдельные списки `images`, `audio`, `videos`; неизвестное расширение — в свой
  список, не в мусор. Ключи ответа — контракт: новый список добавляй в конец, старые не переименовывай.
- Новый тип генерации — сначала тест разбора с реальной формой ответа (сохранённый JSON поставщика), потом обработчик.
- Признак: задача у поставщика `success`, а у тебя «нет результата» или возврат средств без текста ошибки.
