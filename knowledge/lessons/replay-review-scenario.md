# Замечание ревью воспроизводи сценарием ревьюера тем же инструментом до и после починки — дешёвая проверка между дорогими кругами

Контекст: после третьего круга ревью два блокера остались без свежего взгляда субагента (круги исчерпаны);
сценарий ревьюера (его report.json: клики по тексту, ожидания, кадры) повторён тем же инструментом за минуту —
починки подтверждены кадрами без нового круга (~200 k токенов).

Урок:
- Замечание ревью воспроизводи его же сценарием до починки и повторяй после — это дешёвая проверка между
  дорогими кругами; «подтвердить руками» из отчёта — список таких сценариев.
- Сценарий бери из отчёта инструмента ревьюера (шаги, адрес старта), не пересказывай словами.
- Признак: круги исчерпаны или замечание спорит с живой мышью.
