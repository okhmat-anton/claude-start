# Дефолтные промты в БД: правка без архивной копии не доезжает до прода

Стек: любой продукт, где системные промты LLM редактируются в рантайме (лежат в БД,
а дефолты — в коде).

## Ситуация

Промты хранятся в таблице и правятся из админки, а в коде есть словарь дефолтов,
который сидируется при старте. Чтобы не затирать ручные правки владельца, сид
обновляет строку только если её текущий контент совпадает с одной из ПРОШЛЫХ версий
дефолта (список архивных текстов). Меняешь дефолт в коде, забываешь положить прежний
текст в архив — прод молча остаётся на старом промте, а локально и в тестах всё новое.
Симптом ровно один: поведение ИИ на проде не меняется после деплоя, ошибок нигде нет.

## Правило

- Изменение дефолтного промта — всегда ПАРА правок: новый текст + прежний рендер
  того же слага в список архивных версий. Если промт собирается из констант
  (схема JSON, общие блоки правил), архивная копия должна использовать СТАРЫЕ
  константы — заведи `_RULE_V1`, а не ссылайся на изменившуюся.
- Регрессионный тест: текущий дефолт не лежит в архиве, а последняя архивная
  версия не содержит маркера нового правила.
- После деплоя проверить в логе старта счётчик обновлённых промтов
  (`updated N to new defaults`) — это единственное доказательство, что прод переехал.

## Смежное

Правило, которого нет в промте, для ИИ не существует: доменные правила из
документации, протоколов и журналов уроков не влияют на генерацию, пока не попали
в текст промта. Промт-ревьювер («квалити-гейт» перед пользователем) пропускает
всё, что описано расплывчато: работает только явный перечень «REVISE, если …».

Сгенерированный текст — не носитель метаданных. Требование «пиши все величины в
предпочитаемой единице» ИИ выполняет для ЧИСЕЛ, а подпись при этом локализует под
язык ответа — число в фунтах с подписью «кг». Парсер, который вытаскивает единицу
(валюту, часовой пояс) регексом из текста, получает достоверное число и лживую
метку, а дальше пересчитывает величину ещё раз. Правило: метаданные фиксировать в
структуре рядом с данными на момент записи и считать источником истины, суффикс в
тексте — только фолбэк для старых записей; в промте отдельным пунктом требовать
канонический вид подписи (латиницей, из закрытого списка), иначе ИИ её переведёт.
