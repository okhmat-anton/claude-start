# Дешборд из блоков двух ширин в одной сетке даёт дыры — строки выравниваются между колонками; рендерь блоки слотом в два независимых flex-контейнера

Контекст: Дешборд из блоков двух ширин лежал в одной CSS-сетке (три колонки, широкие блоки — span 2): строки выравнивались между колонками, и под короткими блоками слева зияли дыры до 110 px, при длинном списке справа — почти экран пустоты.

Урок:
- колонки разной природы делай независимыми: один именованный слот рисует любой блок, обёртка раскладывает блоки в два flex-контейнера (широкие слева, узкие справа) по списку пользователя; сетка — только для колонок;
- признак: `grid-column: span` у части блоков и блоки заметно разной высоты в соседних колонках;
- цена: ревьюер видит «дыры» на главном экране и считает вёрстку поломанной.
