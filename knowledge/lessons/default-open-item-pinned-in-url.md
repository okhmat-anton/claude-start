# Запись, открытая по умолчанию, закрепляется в адресе

Контекст: страница списка без id в адресе показывала первую запись. Агент добавил новую — она стала первой, и
перечитывание по событию молча подменило открытую у человека запись вместе с его правками в полях.

Урок:
- Неявный выбор делает обработчик — он же возвращает канонический адрес выбранной записи в данных страницы.
- Приложение подставляет его в строку адреса тихо (replace без перечитывания) сразу после первой загрузки;
  дальше перечитывания идут по явному адресу, и порядок списка не важен.
- Признак заранее: любое «если id не передан — берём первую» в обработчике плюс любое автоматическое перечитывание.
