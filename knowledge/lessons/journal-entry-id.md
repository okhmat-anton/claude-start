# Записи журнала правок — со своим id, время — не ключ

Контекст: Откат искал снимок по времени записи. В быстрой проверке создание и удаление попали в одну миллисекунду — две записи с одним временем, откат брал первую (без снимка), проверка плавала через раз.

Урок:
- Каждая запись журнала получает свой id при записи; откат и история работают по id, время — только для показа.
- Если откат по времени всё же нужен (старые клиенты) — брать последнюю запись с таким временем, не первую.
- Признак заранее: ключ записи — метка времени, а тесты и агенты делают несколько правок подряд.
