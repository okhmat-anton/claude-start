# Массовая правка кода регуляркой съедает соседние функции

Контекст: скрипт переписывал десяток декораторов роутов одним `re.sub` с `re.S` и `.*?` от `@router.post(` до
нужного аргумента. Совпадение началось у первого декоратора файла, где аргумента не было, и проглотило пять
функций; склейка аргументов в строку свернула их в одну. Отчёт «переписано: 10» выглядел успехом.

Урок:
- Массовую правку делай по одной замене на уникальный якорь (имя функции, уникальная строка) с проверкой
  «ровно одно совпадение», либо перезапиши файл целиком.
- Регулярке с `re.S` не давай пересекать границу функции: вместо `.*?` — класс без переводов строки
  (`[^\n]*`) или без `@`/`def`, либо ограничитель по отступу.
- После трансформации — компиляция или линтер и дифф по числу строк: «заменено N» ничего не доказывает.
- Испорченный файл восстанавливай из git (сохранив копию) и вноси правки заново, а не чини склейку.
