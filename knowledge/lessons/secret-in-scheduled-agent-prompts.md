# Ключ живёт и в промтах облачных расписаний

Контекст: утёкший ключ API менялся на сервере, а ключ ещё стоял текстом в промтах облачных расписаний
агента; план знал не обо всех — одно нашлось только поиском по всем промтам.

Урок:
- Перед сменой — список всех расписаний и поиск старого значения в каждом промте, включая выключенные.
- Менять между двумя прогонами: сервер, затем промты; ключ — через stdin, не в выводе.
- Сверять диффом: новый промт = старый с заменённым ключом, и ничего больше.
- После — первый прогон каждого расписания проверить по его журналу.
