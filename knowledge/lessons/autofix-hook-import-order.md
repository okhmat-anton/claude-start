# Автофикс-хук (ruff --fix) стирает импорт, добавленный раньше использования, между пошаговыми правками — сначала использование, потом импорт

Контекст: PostToolUse-хук агента гоняет ruff --fix после каждой правки файла. Импорт добавили первой правкой, использование — второй; между ними хук удалил «неиспользуемый» импорт, приложение упало с NameError, хотя обе правки «прошли успешно».

Урок:
- При активном автофикс-хуке порядок пошаговых правок одного файла: сначала использование, потом импорт — либо обе в одном патче.
- Признак заранее: результат правки сопровождается пометкой «hook modified file» — значит, между твоими правками файл меняет линтер, и «висящие» добавления он снесёт.
- После серии правок одного файла перепроверь импорты (grep или запуск), а не полагайся на успех отдельных Edit.
- Якоря следующих правок: хук переформатирует многострочные конструкции (декораторы, сигнатуры) — якорься на
  уникальной строке вроде имени функции или перечитай файл перед правкой.
- Повторилось в проекте трижды — закрепи правилом проекта для путей кода, одного урока в журнале мало.
