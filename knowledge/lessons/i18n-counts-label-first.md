# Счётчик в переводимом тексте без форм множественного числа: «Метка: N» вместо «N things» — верно для любого числа и языка

Контекст: подпись «{n} things need you» дала «1 things need you»; форм множественного числа в словарях нет, и заводить
их на девять языков ради одной строки — дороже, чем переписать фразу.

Урок:
- число в переводимом тексте ставь после метки: «Waiting for you: 1», «Generations today: 3» — верно для любого
  числа на любом языке без правил склонения;
- признак: в ключе перевода число стоит перед существительным («{n} items», «{n} штук»);
- то же для тестов: искать по видимой строке «Метка: N» проще, чем по разметке.
