# Виджет с CDN — скоуп стилей, префикс классов, свои подписи

Контекст: markdown-редактор с CDN в тёмной админке на серверных шаблонах. Тесты по разметке прошли, живой браузер
показал три поломки: свои правила темы не применились, одна кнопка панели растянулась на всю строку, строка
состояния осталась по-английски в локализованном интерфейсе.

Урок:
- CSS виджета подключается блоком страницы после общего стиля и при равной специфичности побеждает: каждое своё
  правило для виджета начинай с класса контейнера страницы (`.page-main .Widget …`), а не надейся на порядок.
- Виджет, который вешает на кнопки класс из имени (`table`, `link`, `code`), ловит стили компонентов приложения —
  включай опцию префикса классов (у EasyMDE `toolbarButtonClassPrefix`) до первой вёрстки.
- Встроенные тексты виджета (подписи счётчиков через CSS `::before`, подсказки, диалоги) по-английски — замени их
  своими элементами из словаря или отключи; признак — любой текст, которого нет в словарях.
- Проверка: живой скриншот в каждой теме и в длинном языке; регрессию закрепи тестом на конфигурацию (префикс
  включён, свои правила начинаются с контейнера).
