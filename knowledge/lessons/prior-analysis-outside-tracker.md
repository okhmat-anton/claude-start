# Прошлый разбор может лежать вне трекера проекта

Контекст: план следующей попытки рекламной кампании собирался по карточке проекта, базе знаний и помеченным файлам. Разбор рекламного кабинета неделей раньше жил только в опубликованном артефакте, и заказчик прислал его посреди работы. В нём был главный риск: прошлые кампании с заявкой на сайте тратили бюджет без видимых заявок, потому что учёт не работал. План пришлось дописывать.

Урок:
- Перед планом следующего шага по теме, которую уже разбирали, просмотри не только трекер, но и список артефактов заказчика за последние недели (инструмент Artifact, действие list). Разборы по теме прочитай.
- Найденное вне трекера перескажи в трекер блоком или комментарием: следующий агент ищет там.
- Признак ситуации: в трекере есть решения и цифры, но нет самого разбора, из которого они взялись.
