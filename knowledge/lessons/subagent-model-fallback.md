# У длинного субагента есть запасная модель и запуск в фоне

Контекст: субагент ревью с моделью, зашитой в шапке роли, упал на лимите сессии (429) и дважды на сетевой ошибке
(ENOTFOUND) — три запуска из пяти не дали результата, время круга ушло впустую.

Урок:
- Модель длинного субагента задавай параметром вызова (`model`), а не только в шапке роли: первый 429 — перезапуск
  на запасной модели той же командой, без правки файлов и без ожидания «лимит отпустит».
- Запуск — в фоне с ожиданием уведомления; повтор после ENOTFOUND — только после `curl` к API, что сеть вернулась,
  иначе сгорает ещё один круг.
- Признак заранее: несколько субагентов подряд в одной сессии — лимит сессии близко, запасную модель держи наготове.
