# Каждое поле для модели проверено в собранном промте

Контекст: шаблон недели нёс название и фокус дня, но запрос дня их не передавал — модель строила «верх: грудь и спина» без тяг; в другой раз пустой вердикт судьи выглядел сбоем инструмента, а промт судьи собирался без кандидатов.

Урок:
- На каждое поле, предназначенное модели, — тест «есть в собранном промте» (строкой, как увидит модель).
- Перед циклом судьи распечатать один собранный промт целиком и сверить с данными; `--dry` печатает и промт судьи.
- Пустой или одинаковый вердикт — сначала вывести промт и его длину, потом искать причину в инструменте; утверждение «в промте есть раздел с кандидатами» — до вызова модели.
