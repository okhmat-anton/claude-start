# Фрагмент документа внутри шаблонной строки — отдельным файлом с экранированием

Контекст: Гайд для агентов — шаблонная строка в главном файле сервера. Новый раздел с кодовыми блоками в обратных кавычках, вставленный скриптом как обычный текст, сломал бы весь файл. Поймано до запуска, но скрипт вставки пришлось переписать.

Урок:
- Готовить фрагмент отдельным файлом ровно в том виде, как он лежит в исходнике: обратная кавычка экранирована, обратная косая удвоена, подстановки ${…} только там, где они задуманы.
- Вставлять скриптом по уникальному якорю с проверкой, что якорь встретился один раз.
- После вставки — проверка синтаксиса файла и живой ответ маршрута, который отдаёт этот документ.
- Признак заранее: документ генерируется функцией с шаблонной строкой, а новый кусок содержит кодовые блоки.
