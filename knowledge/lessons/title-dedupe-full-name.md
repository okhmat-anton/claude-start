# Склейка списков по названию — по полному имени

Контекст: две таблицы игр (чарты магазина и платные хиты) склеивали по названию до двоеточия. Сиквел
«X: New Shores» слился с оригиналом «X» и затёр его продажи, спин-офф «Y: Drawers» получил цифры оригинала.
Ошибку нашёл только независимый исполнитель через час.

Урок:
- Ключ склейки — полное имя без знаков и регистра; пометки вроде «(серия)» — вне ключа.
- Хвост после «:» или « - » у названий из магазина — часто маркетинговый подзаголовок, но не всегда.
  Сопоставлять по началу можно только для тех строк магазина, где второй таблицы нет полного совпадения,
  и со списком исключений для настоящих отдельных игр.
- После склейки — выпиши слитые пары и прочти глазами: десяток строк ловит ошибку сразу.
