# Ползунок дёргается под пальцем: Vue при перерисовке возвращает :value из шаблона — :value должен читать то, что пишет @input

Контекст: ползунки настроек дёргались при перетаскивании: `:value` смотрел на сохранённое значение, а `@input`
писал число в соседнее состояние для подписи. Vue 3 при каждой перерисовке принудительно ставит элементу `value`
(особый случай патча свойств), поэтому ползунок отскакивал к старому значению под пальцем.

Урок:
- У `input type=range` (и любого поля без v-model) `:value` читает то же состояние, которое пишет `@input`:
  `:value="live[name] ?? saved"` — или используй v-model.
- Закрепи тестом по исходникам: у каждого ползунка имя состояния из `@input` встречается в `:value`.
- Признак: подпись рядом с ползунком обновляется на каждом движении (перерисовка), а `:value` — сохранённое значение.
