# Необязательное поле без значения по умолчанию

Контекст: поле часового пояса у входа имело значение по умолчанию «UTC», и каждый вход скриптом переписывал пояс человека — тренировка в четверг записалась пятницей.

Урок:
- Необязательное поле запроса — `None`; сервер трогает хранимое, только если поле пришло.
- День события берётся с устройства человека (клиент шлёт дату), сервер лишь проверяет расхождение.
