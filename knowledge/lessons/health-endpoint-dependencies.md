# Отказ зависимости — это ответ health-эндпоинта, а не ошибка

Контекст: эндпоинт мониторинга, падающий с 500, когда лежит база, скрывает единственный факт, ради которого
написан.

Урок:
- Проба каждой зависимости ловит своё исключение и возвращает свой отказ в теле: статус, задержка, текст ошибки.
  Общий статус: отказ хранилища, без которого не работает ничего, — `down`; вспомогательного (кеш, очередь) — `degraded`.
- Загрузка, память, диск, сеть читаются из псевдо-ФС ядра и стандартной библиотеки — отдельный пакет не нужен;
  где псевдо-ФС нет (машина разработчика на другой ОС), метрика — `null`, а не падение эндпоинта.
- Отдавай два времени работы: процесса приложения и хоста. Перезапуск контейнера виден только по первому.
