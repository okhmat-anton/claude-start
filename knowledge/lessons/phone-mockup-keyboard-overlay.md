# Клавиатура-макет: отступ на корне, листы внутри экрана, фокус не терять на кнопке отправки

Контекст: кликабельный макет показывает, как экран живёт с выдвинутой клавиатурой: на focusin в режиме телефона рисуется декоративная клавиатура, корень получает padding-bottom на её высоту, панель вкладок прячется. Лист заметки с полем оказался разрезан: его `inset: 0 0 var(--kb-h) 0` считал высоту клавиатуры второй раз, потому что containing block абсолютного листа — экран (position: relative), уже сжатый отступом корня.

Урок:
- Клавиатура-макет — один компонент на корне: focusin в режиме телефона → класс на корне с `padding-bottom: var(--kb-h)`; focusout — с задержкой ~250 мс, чтобы тап по кнопке рядом с полем успел сработать; у кнопок отправки `@mousedown.prevent`, чтобы поле не теряло фокус.
- Абсолютные листы и плашки, вложенные в экран с `position: relative`, уже стоят над клавиатурой — отступ им не добавляй; добавил — лист режется пополам на кадре.
- Проверяй кадром с полем в фокусе каждое место ввода (заметка, чат, ответы, поиск): главная кнопка листа должна быть над клавиатурой.
- Признак: `inset … var(--kb-h)` у элемента внутри сжатого контейнера, или на кадре между листом и клавиатурой видно содержимое экрана.
