# Вывод проверки через | tail прячет её код возврата

Контекст: `npm run lint 2>&1 | tail -1 && npm run build` показал пустую строку и пошёл дальше: eslint нашёл ошибку, но статус цепочки взял у tail; ошибка уехала в коммит.

Урок:
- Проверки запускать так, чтобы статус был виден: `команда > файл; echo exit=$?` или без конвейера (`set -o pipefail`, где можно).
- «Линт зелёный» утверждать только по коду возврата, не по хвосту вывода.
