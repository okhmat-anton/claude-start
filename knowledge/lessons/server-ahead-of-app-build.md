# Сервер впереди сборки приложения: новое — только тому экрану, который его знает

Контекст: экраны приложения лежат внутри сборки телефона и обновляются, когда человек её обновит; сервер
выкатывается сразу. Новый вид строки в ответе старый экран показал бы неверно (сбитая нумерация, чужая подпись).

Урок:
- Экран называет свой уровень заголовком в каждом запросе; сервер на время запроса кладёт его в контекст и
  в одном месте решает, что отдать: старому — без нового.
- Без заголовка — самый старый экран. Клиент тестов называет нынешний уровень, отдельный тест — старого.
- Перед тем как добавить в ответ новый вид данных, спроси: что с ним сделает экран прошлой сборки.
