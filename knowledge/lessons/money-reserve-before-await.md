# Деньги внешнего сервиса: проверка потолка и резерв — до ожидания ответа

Контекст: кнопка платного поиска проверяла потолок трат месяца, секунды ждала ответ сервиса и только потом
записывала списание. Два нажатия подряд проходили одну и ту же проверку. Счёт трат лежал в документе с
историей и откатом — откат документа «возвращал» потраченные деньги.

Урок:
- Проверка потолка и резерв суммы — в одном синхронном куске кода до await; после ответа — поправка на
  фактически списанное; соединение не открылось — резерв назад.
- Сервис не вернул сумму списания — считать по цене находки, а не нулём: иначе потолок не двигается.
- Счёт трат — отдельным файлом вне истории документа; ответ того же платного запроса по той же записи —
  из своего кэша на разумный срок.
- Регрессия — два запроса одновременно при потолке на один: ровно один проходит, второй получает отказ.
