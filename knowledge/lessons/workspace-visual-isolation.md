# Визуальное различение окон редактора между проектами

Стек: любой проект, открываемый в VS Code (расширение Peacock). Актуально, когда у пользователя одновременно открыто несколько окон разных проектов.

## Проблема

Несколько одинаковых на вид окон редактора — правка уходит не в тот проект, команда запускается не в том терминале. Ошибка тихая: замечается уже после коммита. Чем больше проектов у пользователя, тем выше цена.

## Правило

В начале работы над любым проектом проверить `.vscode/settings.json`.

- **Файла нет → создать** с Peacock-цветом, чтобы окно отличалось от остальных.
- **Файл есть → не перезаписывать.** Цвет менять только по явной просьбе пользователя.

Требования к цвету:

- Только тёмные и приглушённые тона. Никакого неона и насыщенных цветов: акцент должен спокойно стоять за кодом, а не спорить с ним.
- Оттенок подбирать под тему/бренд проекта (мебель → тёмный орех, платежи → тёмный сине-серый, новости → тёмный чернильный бирюзовый). Бренда нет — любой тёмный десатурированный тон.
- **Проверить занятые цвета перед выбором** — иначе смысл теряется. Одной командой по всем проектам пользователя:
  ```
  find <projects-root> -maxdepth 3 -path "*/.vscode/settings.json" -not -path "*/node_modules/*" \
    | while read f; do echo "$f -> $(grep -o '"peacock.color": *"[^"]*"' "$f")"; done
  ```

Палитра-заготовка (все тёмные, низкая насыщенность):

| Hex | Тон |
|-----|-----|
| `#3C2A21` | орех |
| `#2F3E46` | сине-зелёный сланец |
| `#293241` | тёмный navy |
| `#3A2E39` | слива |
| `#33413A` | хвойный |
| `#3D3B30` | олива/хаки |
| `#40312E` | тёмная терракота |
| `#2B3A55` | индиго |

## Форма файла

Status bar и title bar — тот же оттенок, но темнее (примерно на 25–30 % светлоты), иначе полосы сливаются с activity bar.

```json
{
  "peacock.color": "#2F3E46",
  "workbench.colorCustomizations": {
    "activityBar.background": "#2F3E46",
    "activityBar.foreground": "#e7e7e7",
    "activityBar.inactiveForeground": "#e7e7e799",
    "statusBar.background": "#232f35",
    "statusBar.foreground": "#e7e7e7",
    "titleBar.activeBackground": "#232f35",
    "titleBar.activeForeground": "#e7e7e7",
    "titleBar.inactiveBackground": "#232f3599",
    "titleBar.inactiveForeground": "#e7e7e799"
  },
  "peacock.affectedElements": ["activityBar", "statusBar", "titleBar"]
}
```

## Оговорка

Цвет применяется к окну, а не к папке: у монорепо и его подпроекта цвета разойдутся только если подпроект открывают отдельным окном.
