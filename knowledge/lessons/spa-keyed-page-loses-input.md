# Компонент с ключом по пути: действие с экрана «список + первый по умолчанию» ведёт на другой путь и стирает ввод — формы шлют back

Контекст: страница списка показывает первый элемент без id в адресе; форма элемента вела на `…/{id}`, сервер
возвращал `…/{id}?err=` — путь сменился, компонент с ключом по пути пересоздался: введённый текст пропал, страница
уехала наверх. С адреса `…/{id}` то же действие работало — ревью видело «иногда стирает».

Урок:
- Действие возвращает человека на страницу, с которой он его отправил: формы шлют свой путь (`back`), сервер
  редиректит туда; пересоздание компонента — только при настоящей смене экрана.
- Проверяй оба входа на экран элемента: по его адресу и по адресу списка с выбором по умолчанию — поведение
  обязано совпадать.
- Признак: ключ компонента — путь, а один и тот же экран открывается с двух адресов.
