# Сначала прочитать результат без модели, потом звать модель и судью

Контекст: цепочка «модель выбирает → код считает и собирает текст → судья-модель оценивает». Первый прогон с моделью
и судьёй (кредиты, десятки минут) вернул только дефекты кода: строка дозы пирамиды не называла back-off, лестница
теста уходила ниже разминки, замены брались из соседнего паттерна (прыжки вместо икр), «зачем» обрезалось посреди
слова, в русскую строку попало «the bar». Ни одно замечание не касалось выбора модели.

Урок:
- Когда часть результата собирает код, собери его без модели (путь по умолчанию: первые кандидаты, пустые слова) для
  трёх-четырёх случаев и прочитай так, как увидит человек: строки с числами, подписи, замены, язык. Это бесплатно и
  занимает минуты.
- Дефекты рендера чини и закрепляй тестами до первого вызова модели; судью зови, когда без модели всё читается чисто.
- Признак заранее: в задаче появился шаблон строки, обрезка текста, подстановка имён из словаря или склейка «код +
  слова модели» — каждый такой шов стоит одного прочтения глазами.
