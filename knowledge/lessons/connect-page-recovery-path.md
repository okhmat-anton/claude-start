# Страница «подключи за одну команду» для не-разработчика: путь «не сработало» не должен водить по кругу

Контекст: три круга ревью страницы подключения агента (5 → 7 → 7 из 10). Каждый круг находил ловушку в пути
восстановления: кнопка Copy у образца ключа копировала образец с многоточием; повтор шага с ключом дописывал второй
ключ в файл и ломал команды; совет при 401 для одного из клиентов упирался в отказ команды «файл уже есть».

Урок:
- Шаг с ключом — команда со скрытым вводом, которая создаёт файл и заменяет прежний ключ, а не дописывает; у образца
  ключа кнопки копирования быть не должно.
- Каждый пункт «если не сработало» пройди руками по собственному тексту до конца: куда он отправляет и не упирается ли
  там в отказ другой команды.
- Один основной способ на клиент; у каждого клиента — своя команда удаления и слово про новую сессию или перезапуск;
  оглавление ведёт к каждому клиенту.
- Признак: страница обещает «одну команду», а в тексте есть «вставьте вручную», «создайте файл», «by hand».
