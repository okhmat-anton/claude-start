# Субагент возвращает итог текстом — файл пишет главный агент

Контекст: шесть фоновых исследователей получили задание положить выводы в `findings.md`. Среда запрещает
субагентам писать отчётные .md-файлы, каждый вернул текст с просьбой «сохраните сами». Отчёты на 30–70 КБ
главный агент чуть не перепечатал вручную.

Урок:
- В задании субагенту: данные (CSV, JSON, картинки) — в рабочую папку, выводы — итоговым сообщением.
  Файл с выводами не поручать.
- Итог длинный — сохранять его из журнала субагента скриптом (последний вызов сдачи результата),
  а не перепечаткой: это бесплатно и без опечаток.
- Если отчёт обрезан в превью, полный текст лежит в сохранённом выводе: резать его по маркеру внутри
  текста — по последнему вхождению, маркер часто упомянут и во вступлении.
- Признак заранее: в задании субагенту есть «запиши отчёт в файл .md».
