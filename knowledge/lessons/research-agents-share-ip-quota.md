# Исследователи с одного адреса делят квоту Reddit

Контекст: четыре фоновых исследователя одновременно читали Reddit через RSS с одного адреса — 429 на двух из
трёх запросов, браузерный User-Agent стал получать 403, сводки вышли на 7–12 ветках вместо 12+.

Урок:
- Reddit читает один исполнитель за раз; остальным в задание — первоисточники через WebFetch и поиск.
- Короткий небраузерный User-Agent (`<имя>/1.0`), пауза 12 с, повтор через 50 с после 429.
- Списки поиска и тела постов дешёвые; ветки с комментариями — дорогие, 2–3 на тему; зеркала анонимов не пускают.
- Признак заранее: больше одного агента с «читай Reddit» в брифе.
