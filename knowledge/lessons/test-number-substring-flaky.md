# Тест «числа нет в ответе» подстрокой падает от времени записи — проверять по ключу или с разделителем поля

Контекст: тест «наценки 1.3 нет в данных страницы» искал подстроку `1.3` во всём JSON ответа. Раз в несколько
минут он падал: в отметке времени записи оказывалось «…21.39…». Первый прогон упал, второй прошёл — легко списать.

Урок:
- Отсутствие значения проверяй по ключу (`"coefficient" not in data`) или с разделителем поля (`": 1.3"`), а не
  голой подстрокой по всему ответу: в нём время, идентификаторы, суммы и адреса.
- Признак: в тесте `"<короткое число>" not in <весь ответ>`; тест падает и проходит без правок кода.
- Упал один раз из нескольких — не перезапускай до зелёного: найди, чем прогоны отличались (время, случайный id).
