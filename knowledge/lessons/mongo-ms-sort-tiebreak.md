# Сортировка по дате в Mongo — вторым ключом _id

Контекст: «самый свежий проект» выбирался сортировкой по дате создания. Mongo (и mongomock в тестах) хранит время
до миллисекунды: два проекта, созданные подряд, делили дату и шли в порядке вставки — свежим оказывался старший.
Новый тест падал раз в десяток полных прогонов.

Урок:
- Сортируй по дате и вторым ключом по `_id` в том же направлении: ObjectId растёт, порядок становится однозначным.
- Регрессионный тест — со вставкой двух записей с одинаковой датой напрямую, а не «создай две подряд»: такой не
  зависит от скорости машины.
- Новый тест, создающий записи подряд, прогоняй полным набором несколько раз: редкое падение и есть признак.
