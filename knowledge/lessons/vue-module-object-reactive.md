# Простой объект модуля застывает в computed

Контекст: слова единиц («кг», «см») лежали в обычном объекте модуля, который обновлялся при смене языка; подпись
переключателя в `computed` вычислялась один раз и отставала на одно переключение языка (в русском — «كغ · سم»).

Урок:
- Всё, что меняется при смене языка, единиц или настроек и читается в `computed`, — `reactive`/`ref`.
- Проверка — переключить язык туда и обратно на одном экране и посмотреть подписи.
- Признак: `export const words = { … }`, который кто-то правит в рантайме, а читают экраны.
