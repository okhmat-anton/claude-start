# Форма заказа строится только по моделям каталога с описанными параметрами; модель с пустой схемой честно не предлагается, чтение схемы чинится отдельной задачей

Контекст: у части видео-моделей каталога список параметров оказался пуст — синхронизация не прочитала их схему. Форма
заказа по ним собиралась с нулём длительностей и ценой «—», а заказ падал на валидации с непонятным текстом.

Урок:
- В выбор формы попадают только модели, у которых есть параметры (длительности, разрешения, цена); остальные
  отсеивай при сборке списка, а на явный запрос по API отвечай кодом `model_unsupported` (422), не 500.
- Починку чтения схемы заводи отдельной задачей — не растягивай текущую.
- Признак: пустая цена в пункте списка или ноль вариантов длительности — модель без схемы.
