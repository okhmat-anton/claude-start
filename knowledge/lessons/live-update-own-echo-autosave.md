# Своё эхо живого обновления выбивает курсор из поля с автосохранением

Контекст: страницы подписаны на поток событий сервера и перечитывают данные на каждое изменение; своё эхо
вкладка отсекает по номеру, который клиент шлёт заголовком в каждом запросе. Модуль сервера рассылал событие
с постоянной меткой («agent») вместо этого номера. Пока страницы сохраняли кнопкой, лишняя перерисовка после
сохранения была не видна; на первой странице с автосохранением ответа курсор стал вылетать из поля посреди
набора — каждая пауза в 0,8 с давала сохранение, эхо и полную перерисовку.

Урок:
- Источник события у маршрута, который пишет из браузера: номер вкладки из заголовка запроса, а постоянная
  метка — только запасной вариант для агентов и фоновых задач (`req.headers["x-client-id"] || "agent"`).
- Перед автосохранением поля проверь две вещи: модуль метит события номером вкладки, и страница не
  перечитывает данные, пока поле в фокусе или сохранение ещё в пути (отложи перечитывание до ухода из поля).
- Закрепи проверкой в общем прогоне: обход модулей маршрутов на вызов рассылки с одной строкой вместо
  номера вкладки; старые модули — списком долга, новые в него не добавляются.
