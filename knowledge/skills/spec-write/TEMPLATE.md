Правила исполнения — одинаковы для любого ТЗ, не менять:

1. Иди по этапам по порядку. Между точками проверки не останавливайся и вопросов не задавай.
2. Этап кончается твоей проверкой каждого его пункта с доказательством (файл и строка, команда, кадр) и коммитом.
3. Точка «стоп» — это показ работающего, а не отчёт: подними стенд с пробными данными и без боевых ключей
   (или выложи на тестовый сервер), проверь сам на компьютере и телефоне, открой владельцу и напиши: где смотреть ·
   какие шаги сценария пройти · что проверил сам · где отступил от ТЗ. Жди «дальше»; показ не гаси, пока ждёшь.
4. Правка владельца — сначала в ТЗ (пункт, строка в «Решения владельца», вид пропуска в «Ход исполнения»),
   потом проход по изменённым пунктам, потом код, потом снова показ.
5. ТЗ молчит или спорит с собой: мелкое и обратимое реши сам и запиши отступление; деньги, доступ, данные
   и необратимое — остановись и спроси сразу, это внеплановая точка проверки.
6. Веди «Ход исполнения» по ходу: после обрыва сессии работа продолжается с него.
7. В конце — проверка по ТЗ по всем пунктам и весь сценарий из раздела 2 на показе.
