# Событие при записи заказа, не при старте

Когда: событие или значок «в работе» публикуется, когда задача стартует у исполнителя, а запись заказа в базу
проходит молча — пока заказ ждёт очереди, кабинет ничего не показывает.

Предложение: публиковать событие при самой записи заказа и при каждой смене статуса, не только при старте. Делаем?

Выгода: значок «в работе» появляется в момент действия агента, а не спустя очередь. Цена: один вызов в функции записи, ~3 строки.
