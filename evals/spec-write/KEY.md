# Замер навыка spec-write: ТЗ с заложенными пороками

Учебный проект `project/` — крошечные «Заметки» и ТЗ `technical-docs/share-trash/tz_share-trash.md`, в которое
заложены пороки. Этот файл — ключ: исполнителям замера его **не давать**, им копируется только папка `project/`.

## Как прогнать

1. Скопировать `project/` во временную папку — отдельную копию автору прохода, одну общую читателям.
2. Автор прохода (свежий агент, навык spec-write, человека нет): «доработай ТЗ» — вопросы пишет в «Открытые вопросы».
3. Два читателя по `READER.md` (разные модели) и рецензент простоты по `UX.md` — по исходному ТЗ.
4. Свести по разделу 4 навыка и заполнить таблицу в конце: что поймал автор, что — расхождение читателей,
   что — рецензент. Лишние вопросы считать по трём «ложным следам».
