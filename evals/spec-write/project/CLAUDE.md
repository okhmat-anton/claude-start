# Заметки — правила проекта

Учебный проект для пробных прогонов навыка spec-write: крошечное приложение заметок.

- Стек: Node 20 без пакетов. Сервер — `app/server.js`, одна страница `app/notes.html` со скриптом `app/notes.js`.
- Стенд: `node app/server.js 5180` → http://127.0.0.1:5180/ . Данные в памяти, пробные, после перезапуска сбрасываются.
  Вход упрощён: имя человека приходит в заголовке `x-user`, по умолчанию `anna`. Тестового сервера онлайн нет.
- Кто вызывает — берётся только из заголовка `x-user`. Имени из тела запроса и из адреса сервер не верит.
- Каждое удаление, которое нельзя вернуть, — через подтверждение.
- Ключи и номера записей в общедоступные адреса не попадают.
- Страница помнит выбранное человеком (фильтр, поиск) после перезагрузки.
- Проверка: `node --check app/server.js && node --check app/notes.js`.
